# PYNQ 小车接收上位机

桌面主入口：`PYNQ小车控制台.lnk`。旧的接收上位机快捷方式也指向同一个启动器。

1. 小车和路由器使用独立电源上电；PYNQ 网口接路由器 LAN，C270 接 PYNQ USB HOST。
2. 结束当前在线对话后，电脑连接 `GL-SFT1200-0a0-5G`。
3. 双击快捷方式。启动器通过已核验主机密钥的 SSH 连接 PYNQ；如果没有运行会话，调用已部署的 `start_hybrid.sh --video-only`，然后用当前令牌打开 **Edge 应用窗口**中的原网页控制台。

默认板卡地址为以前实测的 `192.168.8.139`，窗口中可改。若 DHCP 地址改变，可在小车路由器客户端列表中查找 PYNQ。不会自动切换电脑网络。

目前是台架版本：保留原图、真实 PL 图、同帧冻结、实际状态与诊断；方向操控未开放，不解锁电机，不发送驾驶帧，不填写假标定值。默认视频模式不采集 STM32 串口传感器，页面明确显示未采集，而不把未知状态显示为零输出或已锁车。

板端视频运行一小时，关闭启动器或拔掉电脑 USB 不影响板端进程。PYNQ 重启后需要再双击快捷方式启动；尚未配置开机自动启动。

启动日志：板端 `/home/xilinx/stm32_sensors_platform_20261013/receiver.log`。每次会话的启动回执保存在 `receiver_sessions/时间/`，运行证据保存在其下独立的 `evidence/`，避免提前写日志导致程序拒绝启动。桌面启动器只保存板卡地址，不保存会话令牌。

2026-10-14：新候选 `v010_edge_console_20261014_r2` 已部署，完成一小时纯视频、实际无线网页出图与同帧冻结分项验证。网页检查在内置 Chromium 完成，Edge 启动入口已核验；未宣称原生 Edge 专属 UI 验收。完整报告位于 `pynq_fpga/preintegration/evidence/car_full_check_20261014/TEST_REPORT.md`。
