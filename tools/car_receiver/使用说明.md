# PYNQ AR 小车完整控制台

2026-10-26：桌面的 **PYNQ小车控制台** 和 **PYNQ小车接收上位机** 均改为 `tools/open_car_console.py`。双击先在 Edge 打开完整控制台，可离线浏览四个栏目；打开本身不会切换 Wi-Fi、连接板卡或启动电机。没有实测数据时显示未知。

## 页面功能

| 栏目 | 功能 |
|---|---|
| 驾驶总览 | 原图／真实 PL 图切换、同帧冻结、视频参数、实际距离和 LOCK/PWM、实测速度和里程、风险状态、趋势、方向控制 |
| 传感器与标定 | 红外、超声波、双轮编码器、串口计数与采样年龄、通道联调、人工距离和计数生成标定、导入／下载／应用并读回 |
| 记录与诊断 | 会话记录、JSON/CSV 导出、历史回放、状态事件、板端日志、联调报告 |
| 演示流程 | 系统介绍→实时感知→AR 对比→手动操控→安全响应→结果展示；全屏和简化演示视图 |

点击“打开连接助手”才运行原来的连接程序：连接已保存的小车热点，核验板卡身份，获取本次服务入口。可以取消或直接关闭连接窗口；后台命令窗口隐藏。也可以从“连接设置”粘贴本次启动链接。板卡最近一次实测地址是 `192.168.8.139`。

连接助手核验**板上当前服务**是否为完整控制台且支持红外仅提示策略。旧“受限试跑”服务或不兼容服务会明确提示需要升级，不再打开旧页面冒充连接成功。新版仍需部署配套板端程序、FPGA bit/HWH 和 STM32 固件；电脑页面更新不会自动升级板卡。

## 操控和标定

完整服务启动于“仅观察”，不自动解锁。查看实际回包、完成有效双轮实测标定后，切到“手动驾驶”，接管，再手动解锁。按住 WASD 或方向按钮移动；松开、空格、失焦、断链或数据超时停车。请求 PWM 与 STM32 实际反馈分开显示。

当前操控配置为 PWM 上限 400、连续单次动作上限 1 秒；达到上限停车，需松开并重新接管、解锁。服务端保留 PL 风险判定、感知有效期、UART 租约与 STM32 锁车检查。

v0.11 起红外完全不参与停车、锁车、解锁和驾驶许可判断：检测到障碍、数据失效或断线都只提示。页面单独显示真实红外状态；超声波近障、关键数据失效、编码器故障、通信超时和人工停车仍按原规则处理。该策略须配套更新 FPGA 与 STM32，不能只替换前端。

SCALE 是编码器计数换算为实际距离的标定系数。SCALE 0 / 0 表示左右轮尚未完成有效标定，不能计算可信的车速和里程，也不能据此判断编码器接坏；需要实测推行距离和两轮计数差，页面据此生成各自系数。

用户要求沿用先前方案计算系数：1:48、13 线、四倍频、名义轮径 65 mm，每圈 2496 计数，左右 SCALE 均为 5362（0x14F2）。包内 `desktop/nominal_scale_plan.json` 保存计算依据，标记为方案估算且未写入硬件；方向仍需按当前设置和实际计数确认。这是已有 `TT_48_ORIGINAL_WHEEL_FRONT_2` 名义预设，不等同于实测标定，当前完整驾驶入口仍检查实测来源。

标定时先物理断开电机动力、保留编码器连接，在页面据实更新动力状态。记录起点，尺量向前推动距离，记录终点，输入毫米数并确认实测来源，生成标定 JSON，应用后检查读回。方向在当前 DIR 配置上根据计数正负修正，不能用名义轮径充当实测。重新接入动力后在仅观察模式据实更新状态，再进入手动驾驶。

记录文件不保存连接令牌。导入历史记录会撤销控制并暂停实时视频；退出回放只恢复查看，不自动接管。演示流程按钮只切换讲解步骤，不自动驱动车辆。

关闭 Edge 窗口即可退出电脑控制台；本地服务在没有页面心跳约 90 秒后退出。关闭或切出实时页面会请求停车，板端仍有独立超时检查；关窗口不等于关闭板端服务。连接助手与本地控制台分别可关闭。

## 本轮验证和实物边界

本地回归覆盖红外触发、失效和序号回退，验证它们不会独立阻止解锁或触发停车；同时保留超声波故障停车检查。浏览器联调用本地模拟 API/图像，证据明确标注为非实车。本轮没有重新连接小车网络、部署完整服务或发送运动命令。具体结果见新包内验证记录。

编码器尺度、制动、电池给核心板供电、相机与控制并行长稳仍需现场实测。此前 30 分钟联合稳定测试曾出现采样错误和调度超时，不能将本地页面验证视为整车长稳通过。
