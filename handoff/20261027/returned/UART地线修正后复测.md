# 地线修正后双板通信复测

2026-10-27 09:55（北京时间）实测：**PYNQ 与 STM32 的锁车查询通信通过。**

用户先确认重新插紧 JB9/JB10，随后确认把扩展板 GND 从 JB8 移至 JB11。本次在这些接线修改之后复测，未分别隔离每项修改的作用，不能将所有历史故障归为单一根因。

| 项目 | 本次结果 |
|---|---|
| PYNQ 管理串口 | 本机 COM10，Linux 控制台正常 |
| 两板串口 | /dev/ttyPS1，115200 8N1 |
| 查询与有效回复 | 80 / 80 |
| 独立 CRC-16/CCITT-FALSE 复核 | 80 帧通过，错误 0 |
| 会话与请求号 | 单一会话，恰好按顺序回复 1～80，无重复/漏配 |
| 实际执行器状态 | 全部 LOCK=1、左右 PWM=0 |
| 超声波 | 80 帧均有效，距离 631～640 mm |
| 红外 | 80 帧均有效，掩码均为 0；未做遮挡响应测试 |
| drop | 所有反馈为 0 |
| fault | 所有反馈为 41（0x29），非零锁存原因仍保留；本次没有发送解锁或清除指令 |
| PYNQ 版本 | 板上仍为 r16，r17b 尚未部署 |
| 结束状态 | 控制台服务保持停止，串口已释放 |

串口内容已从上次的 Q1/PSTOP 原样回显变为真正的 S1 传感器与执行器反馈。本轮只发送 Q1/PSTOP，没有运动、解锁、MCU 烧录或 FPGA 重新加载。

结果只覆盖本次短时通信。编码器、传感器动态/故障响应、电机运行、视频、联合稳定性和整车验收不在本次通过范围。

原始证据：`board_locked_query-095546.json`。独立审计：`地线修正后复测.json`。
