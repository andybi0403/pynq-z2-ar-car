# 双前轮编码器电平转换PCB设计需求（交同学画板版）

## 1. 设计目的与范围

设计一块用于PYNQ-Z2与两只霍尔编码器TT电机之间的编码器信号转接板。电机为1:48版本，只安装左前、右前两只编码器电机。转接板只处理编码器供电和A/B相信号，不承载电机动力电流，不连接TB6612电机输出。

编码器板按4.5～5V供电、A/B输出属于5V逻辑域处理。PYNQ-Z2 PL引脚只允许3.3V逻辑，因此四路A/B必须经过3.3V供电、输入耐受5V的SN74LVC245A后再进入PYNQ。

本板必须使用完整料号`SN74LVC245A`。不得换成74HC245、74HCT245、TXS/TXB系列或BSS138双向电平转换板。

## 2. 已冻结的PYNQ连接

| PCB网络 | PYNQ连接 | FPGA管脚 | 方向 | 说明 |
|---|---|---|---|---|
| `QEI_L_A_3V3` | Pmod B `JB1` | W14 | PCB→PYNQ | 左前轮A相，QEI0 A |
| `QEI_L_B_3V3` | Pmod B `JB2` | Y14 | PCB→PYNQ | 左前轮B相，QEI0 B |
| `QEI_R_A_3V3` | Pmod B `JB3` | T11 | PCB→PYNQ | 右前轮A相，QEI1 A |
| `QEI_R_B_3V3` | Pmod B `JB4` | T10 | PCB→PYNQ | 右前轮B相，QEI1 B |
| `QEI_OE_N` | Pmod A `JA9` | W18 | PYNQ→PCB | 低电平使能LVC245；配置前必须默认禁用 |
| `VCC_5V_ENC` | Arduino POWER头 `J7 pin 4` | — | PYNQ→PCB | 只供两块霍尔编码器板 |
| `VCC_3V3` | Pmod A/B的3.3V电源脚 | — | PYNQ→PCB | 只供LVC245及其上拉；Pmod电源脚不是5V |
| `GND` | PYNQ任一可靠GND脚 | — | 公共参考 | 5V、3.3V、编码器与PYNQ必须共地 |

不要改变上述信号顺序或把左右通道互换。如PCB走线必须交换，应在原理图网络名、丝印和交付说明中同时明确，不能只在口头说明。

## 3. 接口要求

全部外部接口均预留2.54mm直插排针焊盘，默认焊接公排针，便于使用母对母杜邦线。排针旁必须逐针印完整网络名，不能只印`J1/J2`。建议同时保留同网络测试焊盘。

### 3.1 左、右编码器输入

各使用一个1×4、2.54mm排针，板边放置：

```text
J_ENC_L：GND | L_A_5V | L_B_5V | +5V_ENC
J_ENC_R：GND | R_A_5V | R_B_5V | +5V_ENC
```

- `+5V_ENC`仅供编码器霍尔板，不能接电机正极。
- 两根电机动力线不进入本PCB，继续接TB6612输出。
- 实物PH2.0-6P线束的颜色不视为可靠依据；接线前按厂家针序并用万用表确认正极、负极、A相和B相。
- 由于杜邦排针无防反插结构，`+5V_ENC`端须使用方形焊盘、醒目`5V`丝印和三角形Pin 1标记；建议线束做好热缩管标签。
- 可额外预留不贴装的PH2.0接口焊盘，但不得在未核实实物插座方向和封装后下单贴装。

### 3.2 PYNQ侧QEI输出

使用一个1×5、2.54mm排针，顺序固定：

```text
J_QEI_OUT：L_A | L_B | R_A | R_B | GND
```

其中四路均为经过LVC245转换后的0～3.3V信号。丝印同时标注对应关系：

```text
L_A→JB1   L_B→JB2   R_A→JB3   R_B→JB4
```

### 3.3 控制与3.3V供电

使用一个1×3、2.54mm排针：

```text
J_CTRL：OE_N | 3V3 | GND
```

- `OE_N`通过杜邦线接Pmod A `JA9/W18`。
- `3V3`取自Pmod的3.3V电源脚，只给SN74LVC245A及上拉电阻供电。
- `OE_N`不得硬接地，不采用人工跳线作为正常运行使能方式。

### 3.4 编码器5V供电

使用独立1×2、2.54mm排针，避免5V与3.3V在同一排针上误插：

```text
J_ENC_PWR：5V_ENC | GND
```

- `5V_ENC`用单独杜邦线连接PYNQ-Z2 Arduino POWER头`J7 pin 4 / VCC5V0`。
- PCB上不预留第二路STM32/小车5V并联输入，避免两个5V电源互相倒灌。
- 5V与3.3V接口在PCB上应有明显间距，并分别印`ENCODER 5V ONLY`和`LOGIC 3V3`。

## 4. SN74LVC245A原理图要求

建议采用TSSOP-20封装的`SN74LVC245APW/PWR`或嘉立创库存中可确认完整料号、封装和厂家数据手册一致的器件。下单前再次核对元件库符号与封装引脚号，禁止仅凭库名称放置。

| LVC245引脚/通道 | 连接 |
|---|---|
| `VCC` pin 20 | `VCC_3V3` |
| `GND` pin 10 | `GND` |
| `DIR` pin 1 | 固定接`VCC_3V3`，方向为A侧输入、B侧输出 |
| `/OE` pin 19 | `QEI_OE_N`，另接10kΩ上拉至`VCC_3V3` |
| `A1` pin 2 | `L_A_5V` |
| `A2` pin 3 | `L_B_5V` |
| `A3` pin 4 | `R_A_5V` |
| `A4` pin 5 | `R_B_5V` |
| `B1` pin 18 | `QEI_L_A_3V3` |
| `B2` pin 17 | `QEI_L_B_3V3` |
| `B3` pin 16 | `QEI_R_A_3V3` |
| `B4` pin 15 | `QEI_R_B_3V3` |
| `A5～A8` | 分别接地，禁止悬空 |
| `B5～B8` | 不连接外部接口，可留小测试焊盘但不得与其他网络相连 |

注意：上述引脚号按标准20引脚SN74LVC245A封装列出，画板人员仍须以实际选用封装的数据手册和嘉立创封装库复核一次。

## 5. 电阻、电容与测试点

### 5.1 必装元件

| 位号建议 | 参数 | 连接与布局 |
|---|---|---|
| `R_OE` | 10kΩ，1%，0603/0805 | `OE_N`上拉至3.3V，使PYNQ未配置、复位或断线时转换器默认高阻禁用 |
| `C_U1` | 100nF，X7R，≥10V，0603/0805 | 紧贴U1的VCC与GND引脚，走线尽可能短 |
| `C_5V_BULK` | 10µF，X7R，≥10V | 紧靠`J_ENC_PWR`，接5V与GND |
| `C_5V_L` | 100nF，X7R，≥10V | 靠近左编码器接口，接5V与GND |
| `C_5V_R` | 100nF，X7R，≥10V | 靠近右编码器接口，接5V与GND |
| `C_3V3_BULK` | 1µF～4.7µF，X7R，≥6.3V | 靠近U1，作为3.3V局部储能 |

编码器资料已经说明板载上拉，因此四路A/B不得再装到5V或3.3V的上拉电阻，PYNQ XDC也不启用内部PULLUP。

### 5.2 建议测试点

至少预留以下圆形测试焊盘并印网络名：

```text
TP_5V, TP_3V3, TP_GND, TP_OE,
TP_LA_IN, TP_LB_IN, TP_RA_IN, TP_RB_IN,
TP_LA_OUT, TP_LB_OUT, TP_RA_OUT, TP_RB_OUT
```

测试点应能被万用表表笔、示波器探头夹或逻辑分析仪夹可靠接触。至少放置一个独立GND探头焊盘在信号测试点附近。

## 6. PCB布局布线要求

- 两层板、FR-4、1.6mm、1oz铜即可；板尺寸以安装方便为准，建议控制在约40mm×50mm以内。
- 底层尽量保持连续GND铺铜，避免把地平面切碎；所有外部地最终连接同一GND网络。
- 5V输入区、编码器5V信号区和PYNQ 3.3V输出区在板上按方向分区，丝印画出`5V SIDE → 3.3V SIDE`。
- U1放在输入和输出排针之间；100nF去耦电容紧贴U1 pin20/pin10回路。
- A/B信号走线短且并行长度大致接近，远离电机动力线、TB6612输出和大电流回路。
- 建议普通信号线宽≥0.20mm，3.3V/5V/GND主干≥0.50mm；接口附近避免细颈。
- 不需要做阻抗控制，但不要让四路信号绕板或形成大环路。
- 预留2～4个安装孔，建议M2.5/M3通孔并留足铜皮安全距离；板背面不得因螺柱接触造成短路。
- 芯片pin 1、所有排针pin 1、5V、3.3V、GND、左右和输入/输出方向必须有清晰丝印。
- 板面印警告：`ENCODER ONLY - NO MOTOR POWER`、`5V INPUTS / 3V3 OUTPUTS`。

## 7. 禁止事项

1. 编码器A/B的5V信号不得绕过SN74LVC245A直连PYNQ。
2. 不得把SN74LVC245A的VCC接5V；它在本设计中必须由3.3V供电。
3. 不得把`/OE`硬接GND；必须保留10k上拉和JA9控制。
4. 不得从Pmod的电源脚取5V；Pmod A/B电源脚为3.3V。
5. 不得把PYNQ 5V和STM32/小车5V并联。
6. 电机正负线、电机启动电流和堵转电流不得经过本PCB。
7. 不得仅凭杜邦线颜色、厂家线束颜色或网络名猜测实物针序。
8. 不得用电阻分压、普通74HC245、TXS/TXB或BSS138模块替代本方案。

## 9. 下单前审查清单

- [ ] U1完整料号确为SN74LVC245A，VCC=3.3V，A侧为5V输入，B侧为3.3V输出。
- [ ] `DIR=3.3V`，`/OE`有10k上拉并连接独立`OE_N`接口。
- [ ] 左A/B到JB1/JB2，右A/B到JB3/JB4，未发生左右或A/B静默互换。
- [ ] 编码器5V只来自J7 pin 4，Pmod 3.3V只供LVC245。
- [ ] 5V、3.3V接口物理分开且丝印清晰。
- [ ] A5～A8不悬空，B5～B8不接外部负载。
- [ ] U1近端100nF、5V入口10µF、左右接口100nF已放置。
- [ ] 四路原始输入和四路转换输出均有测试点。
- [ ] 所有外部连接都有2.54mm杜邦排针焊盘和逐针丝印。
- [ ] PCB上没有电机动力网络，也没有两个5V电源并联路径。
- [ ] ERC/DRC无未解释错误，封装方向与pin 1已人工复核。

## 10. 焊接后、连接PYNQ前验收

1. 不接PYNQ、不接编码器，检查5V与3.3V之间无短路，所有GND导通。
2. 仅接3.3V，确认U1 VCC约3.3V，10k上拉使`OE_N`为高，四路B输出处于高阻；芯片不得异常发热。
3. 接入5V但先不接PYNQ信号，确认编码器接口电压为4.5～5.0V，3.3V轨没有被抬高或倒灌。
4. 用信号源或手转编码器输入A/B，在`OE_N`低时测得B侧为0～3.3V；`OE_N`高时输出禁用。
5. 最后才用杜邦线连接PYNQ；先断开电机动力，分别检查PL未配置、同步复位和复位释放三个阶段：`OE_N`应依次保持高、高、低。
6. 通过示波器/逻辑分析仪确认5V侧与3.3V侧波形、无明显振铃和毛刺，再进行手转10圈约24960计数的QEI验收。

实物电平、上电顺序和计数验收完成前，本PCB只能标记为“设计完成/待实测”，不能标记为可发布硬件。
