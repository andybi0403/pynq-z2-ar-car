# 技术方案与接线

本系统是双 MCU/FPGA 协作的感知、显示与受监督电机执行项目。STM32 采集超声波/红外并执行电机 PWM、锁车；PYNQ PS 管理 UART、视频和网页；PL 使用统一时基采集 QEI、接收注入传感器、生成原子快照、计算风险并执行 OSD/Sobel/DMA 视频路径。没有证据可宣称电机 PID 闭环或自主导航已经完成。

```text
超声波 / 红外 → STM32 → UART → PYNQ PS → PL 原子传感器批次 / 风险核
双轮编码器 → 电平转换 PCB → PL QEI → 速度 / 里程 / 双轮差
USB 摄像头 → PS / DMA → PL 图像流水线与 OSD → DMA 回传 / 浏览器 / HDMI
浏览器意图 → PS 控制监督 → STM32 PWM / 实际 LOCK、PWM 回传
```

## UART 当前方案

| PYNQ 标记 | 实际连接的扩展板丝印 | 说明 |
|---|---|---|
| JB9 = PMOD B 第 9 针，FPGA V12 | TX | 生产 FPGA UART TX；丝印采用蓝牙模块视角 |
| JB10 = PMOD B 第 10 针，FPGA W13 | RX | 生产 FPGA UART RX |
| PMOD B GND | GND | 共地 |
| 电源正极 | 不连接扩展板 VCC | 不并联不同电源正极 |

JB 是 PMOD B，JA 是 PMOD A；SWIO/SWCLK 为下载调试口，不能代替 UART。核心板插满扩展板，不要求往已被占用的 PA9/PA10 排针额外插线。蓝牙模块拔下。历史通过条件：BOOT0=0、S5=OFF、核心板 microUSB 供电。**该表是历史成功接法，本次相同信号线仍失败，状态见通信时间线。**

下载是另一条已确认路径：电脑 USB 接扩展板，COM10、S5=ON、BOOT0=1 并复位，首字节 0x7F。芯片返回 0410；本次 128 KiB 读写比对成功。完成后 BOOT0=0 并复位；下载成功不自动意味着 PMOD 应用链路成功。

接线权威依据：[18_UART恢复与S5实测](../../docs/03_硬件与接线/18_UART恢复与S5实测_20261026.md)。10 月 14/22 日旧方案保留为历史，发生冲突时不要覆盖这次实测结论。供应商原理图为“stm32-4wd小车零件资料/YB-EVF01 VER4.5.pdf”，按实际装配确认，未测量的内部网络通断不能写成定论。

## 编码器、电平转换与标定

按 [PCB 需求](../../docs/03_硬件与接线/12_双前轮编码器电平转换PCB设计需求_20260920.md)、[实物审查](../../docs/03_硬件与接线/15_实物PCB与整车接线矛盾审查_20261013.md)、[参数核定](../../docs/03_硬件与接线/10_霍尔编码器TT马达电气与QEI参数核定_20260919.md) 和当前 XDC/board manifest 核对通道，不按照片方向猜 PMOD 针序。

旧方案名义参数：轮直径 65 mm、13 PPR、48 倍减速、四倍频，轮轴名义 2496 count/rev：
`SCALE = round(π × 65 / 2496 × 65536) = 5362 = 0x14F2`。
它表示每个计数对应的毫米距离乘 65536，实际约 0.0818 mm/count。该值是名义预设，measured=false；当前板上 SCALE=0，不冒充已实测应用。

接手需实测左右轮完整转数/计数、运动正方向与地面距离，记录轮胎、供电和地面条件，再通过控制台生成、应用并读回标定。静止时计数 0 并不证明编码器断线；原始计数、非法跳变和转轮方向要共同判断。

## 显示与安全语义

页面保留请求值和实际 STM32 LOCK/PWM 的区别；未得到实际回包不能显示“已解锁”。超声波、编码器质量、采样新鲜度、驾驶意图租约各自有效；心跳不刷新旧数据。红外触发/失效/断线全部只告警，按最终用户要求不参与停车/解锁。

处理视频与原图可做同帧冻结对比；报告依据当前 wireless_dma / native 路径，旧“只用 PS OpenCV 叠图”的方案文档不能当作最新实现。端到端物理延迟、真实制动距离、最终 HDMI 色序仍需实测。
