# 普通电机演示版 v0.13

契约 0xC425100D，配套本包 STM32 程序、bit/HWH、主机程序；不能混用旧固件。

有效前方距离 ≤250 mm 自动阻止前进。无回波、无效或过期测距本身只显示告警，不独立锁车；已经确认的近障碍须收到有效 >250 mm 测距才解除阻挡。红外、编码器、视频和估算里程不作为停车依据。

网络包短暂迟到会被丢弃，不延长上一个命令的有效期。控制连接断开或连续 500 ms 无新有效操作时停车；板端命令/控制循环失效、实际执行器回包持续缺失、非法控制指令等仍停车。一次 HTTP 状态查询失败不切断正常的 WebSocket 控制。100–200 ms 单次采样延迟只记告警；达到 200 ms 停车，恢复后可重新解锁，无需因一次延迟重启服务。

启动时锁车。手动接管、解锁后按住方向键；松手、失焦、内部切页归零且保留接管。急停、退出、历史回放或真正断联撤销控制，恢复后需重新接管/解锁，不自动重放旧运动。默认 PWM 1800，上限 2400，无连续按住时长上限。默认会话 duration=0，表示运行到主动停止或故障，不再 30 分钟自动退出。

服务名为 pynq-car-demo-plain.service，路径 /home/xilinx/v013_plain_motor_demo_20261028_r3。随包服务初始记录电机动力已断开，供静态验证。实际连接动力后，应在页面据实确认连接状态，再接管、解锁；这项记录不是物理断电装置。

桌面入口 desktop/open_console.pyw。USB 调试线用于调试和更新，浏览器控制仍需要电脑与 PYNQ 的网络连接。

估算里程来自实际 PWM 回包与人为设定系数，只用于展示，不能当作实测里程。离线测试及 FPGA 构建结果在配套源码包 validation/ 与 build/r3_artifacts 中；实物制动、地面行驶和现场网络仍需联合验证。
