# 底盘、供电、接线与PCB

## 最小故障隔离

适用：串口枚举正常但应用通信异常、固件错误计数增长、无法区分软件和底板问题。先分清ROM下载、SWD调试、应用UART、BLE透传的路径；COM口存在只证明枚举。

使用停止电平的最小固件，只开启被测UART和固定心跳；记录发送次数、RX字节、ORE/FE/NE/PE，区分硬件错误与协议拒绝。比较发送器开启/关闭、核心板插回/脱离底板、原UART/旁路UART，每次只改变一项，核对供电、接地、TX/RX和独占占用。发射与接收两个方向分别证实。

案例：9月9日最小USART1固件插在底板上3秒错误150次；关闭发送器错误0；核心板脱离底板后发送6次错误0。可缩小到插回底板后的CH340/线路路径，不能据此断言PA9/PA10硬短路或具体器件损坏。USART2旁路收到心跳也不自动证明双向通信。来源见[项目索引](project-map.md)。定位完成后恢复已核验正式固件再谈应用测试。

BLE先按实物丝印/固件确认型号，再查实际服务和应用连接方式。JDY-23的记录提示不能把系统传统蓝牙配对当成BLE透传连接方法；这一结论不套用所有蓝牙模块。旧改装总纲仍写蓝牙4.0，后期审查写JDY-23 BLE5.0，按实物和当前记录解冲突。PYNQ/DAP与蓝牙不能同时驱动同一路UART。

## 板级事实表

每条外接信号记录：设备/网络名、方向、连接器针号、FPGA PACKAGE_PIN或PS MIO/EMIO、bank电压、IOSTANDARD、输出类型、有效电平、转换器、上电默认、来源位置、实测状态。

本案例交叉核对官方XDC、板文件XML、两份原理图与实物修订版。连接器针号不能写成PACKAGE_PIN；旧教程、其他开发板、厂商例程或导出的HWH不替代原理图。只启用实际端口；board_files按工程级路径引用，先验证当前Vivado兼容，不替换全局板文件。

资料冲突时保留未核实值并说明哪一个测量能解决。无实物时可以完成接线设计和静态核对，不能把`electrically_verified`改成true。

## 电源与机械

PYNQ与小车动力电源按当前方案分开，接口只连接核实过的信号与参考地；避免两个5V正极并联/倒灌。按实际板卡手册核对电源输入、跳线、插头极性与电流能力；不把历史12V建议当新板通用参数。

采购前核对：电机尺寸/轴/减速比、安装孔、轮胎配合、插座朝向、封装、信号电平与电源能力。PCB、CAD和Gerber文件存在不代表已生产或验收。板卡/相机/电池固定要留绝缘、重心、散热、线束拉力释放和检修空间；HDMI/网线不能由插座承担车体运动拉力。测试先物理断开电机动力线，软件STOP不替代这一台架条件。

## 电平转换与编码器PCB

5V Echo/A/B不能直接接3.3V PL；先核实源输出类型、实际最高电压、转换器完整料号/封装及断电时输入容限。开漏与推挽分开画电路；不能从“LM393可以3.3V供电”推断整个红外模块共模范围和输出可靠。

本案例双前轮转接板采用完整`SN74LVC245A`：3.3V逻辑供电，固定方向，`/OE`上拉默认禁用，由核实后的PL脚显式控制；5V只供编码器霍尔板，不承载电机动力电流。四路A/B保留左/右与相位映射；未用输入不悬空，去耦靠近器件，测试点/丝印逐针标明网络。HC/HCT245、TXS/TXB或BSS138模块不能作为本设计直接替换件。

制作前从`12_双前轮编码器电平转换PCB设计需求_20260920.md`读取最新网络表；再检查元件符号↔数据手册引脚↔封装↔Gerber的一致性，ERC/DRC、Pin1和连接器镜像方向、丝印、防反插、5V/3V3隔离及地连续性。不要直接从本skill重抄引脚表。

未上电板先做连续性/短路检查，再断开PYNQ验证供电和输出，最后接逻辑端逐项测量。接线颜色不作为针序证据。以上属于待执行验收方法，本次未声称PCB已通过这些实测。

## 轮轴计数和标定

13 PPR在电机轴，轮轴x4计数需乘减速比；本资料1:48为2496，1:90为4680，仍需实物核对。不能把13×4=52当实际轮轴CPR。

用加载滚动距离与对应合法计数分别标定左右`mm/count`，记录方向/轮映射、过滤、零速观察窗口、来源/版本和是否实测；检验正转/反转、不同初始AB、非法沿和不同速度。名义65mm/5362是对照，不是带载结果。生产SCALE复位0保持无效。

标定配置作为事务：撤销命令、确认静止/断开电机、先清双轮SCALE、写参数、逐项读回；失败两轮均未标定。测量或接口版本改变时重新核验，不沿用旧文件。机械制动和接电机运动测试另立流程；当前LAB_ONLY只做手转/滚动台架标定。
