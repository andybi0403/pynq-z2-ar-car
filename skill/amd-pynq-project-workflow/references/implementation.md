# RTL、PS、视频与实际控制闭环

## 契约与原子数据

先定义单位/定点格式、符号/饱和、位宽、复位、时基、更新事件、valid/fault/seq和原子提交。机器源`register_map.json`生成RTL常量、Python常量和说明；升级消费者与HWH后才声明新候选。接口文档中的历史地址表按其版本读取，不和当前表混用。

本小车用共同100MHz/64位tick、统一AXI-Lite地址空间和一次全局快照；读取时触发快照、等待epoch改变、读全部影子、高低字，再核对epoch未变。来源未提交数据不能泄漏到影子；同拍更新/触发、双轮同拍完成分别验证。元数据不要挤占时间高位。

32位100MHz时间约42.95秒回绕；年龄用无符号差值且比较窗小于半模周期，注意起点/位宽。PS monotonic不能直接减PL tick，需映射和不确定度。IR变化时间与里程最后边沿不是周期采样年龄，静止时不机械地套过期规则。

## 传感器、QEI和里程

- US：同步Echo、开始时锁存测量配置；正常/无回波/卡高/超范围生成同批data/valid/fault/ts。异常计数用本次fault，IR变化不续US年龄。核算周期+超时+处理的最坏发布间隔，而非只看名义间隔。
- QEI：同步/组合稳定滤波，先接受初始相位，再按合法跃迁x4计数；上电AB非00不虚构运动。首次沿、反转首沿、非法沿、溢出撤销周期，两个同向合法沿后恢复。
- T法速度：`floor(SCALE × tick_hz / period_ticks)`得到Q16.16 mm/s，方向后饱和；SCALE单位Q16.16 mm/count。使用独立单位推导和数值参考；低速不能无说明改为短窗M法。吞吐不够时明确overrun与恢复，普通计算保留上一完整批及年龄。
- 里程：合法边沿累加SCALE；有符号位移随反转减少，累计路程只增加；配置变化/清零开始新epoch。非法沿、溢出和诊断饱和的无效恢复条件分别定义。静止不发布假运动/新测量；测试负值、高低字、溢出和不同epoch。

## 风险流水与执行器

动态安全距离的单位/舍入、速度边界、故障优先级和方向语义先固定。制动减速度与反应时间的构建常量登记来源，不能当实测。流水中阈值、故障位、命令、时间戳和序号同时延迟；逐拍不同输入验证批次配对。保留吞吐与总反应预算。

STM32是最终锁存层：上电锁车、采样过期/意图租约过期/协议错误锁停、STOP取消待释放；满足安全保持和显式释放后，等待新驾驶意图及真实新反馈，不能恢复缓存PWM。黄色限幅也不能续意图租约，风险回绿不能重放旧高PWM。

按当前权威C和协议确认帧字段/长度/校验和覆盖位置/范围、NUL与非ASCII拒绝、嵌套帧头重同步、接管/残帧/ISR边界。演示版与对接版独立构造校验合法但字段非法的反例，避免早拒绝掩盖未测分支。反馈依据实际PWM/LOCK/FAULT，不能读请求缓存冒充执行。

主机分开更新sample和command；读写/关闭有超时，短写/线程退出记录为故障。协调层/MMIO异常也必须沿可用UART路径请求STOP。保留主机与实际生产C DLL闭环，不用复制的Python安全模型替代权威执行器。

固件集成还需检查启动向量、data/bss初始化、链接器Flash/RAM边界、栈余量、SysTick和实际USART IRQ；默认异常进入停止路径。IWDG喂狗位置与最长阻塞时间一起审查，避免主循环停止而中断仍喂狗。构建体积和零编译警告不证明启动/中断正确，不能用上一轮遗留HEX作为本轮成功产物。

## USB到HDMI的数据流

本案例路径为USB相机→FFmpeg解码→PS帧缓存→VDMA读DDR→元数据解析/PL OSD→HDMI；数据缓存所有者、flush/提交、回收和帧队列策略逐段说明。软件原型可验证布局，最终宣称PL叠加需真实生产像素链路证据。

AXI4-Stream只在posedge `VALID&&READY`推进像素；随机背压时payload/sideband稳定。SOF/EOL、ROM延迟、色序、BGR0到RGB888和异常帧边界一起验证。状态仅在已接受SOF锁存；生产OSD实际输出对独立参考逐像素比对，含全帧和负值/无效状态。

视频与控制使用独立线程，控制发布不可变快照，视频消费；加载Overlay一次且有OS互斥和bit/HWH身份检查。页面只消费共享会话与配置队列，不另开MMIO。摄像头启动失败、stderr堵塞、短帧、拔出/卡住、HDMI异常、重启/清理分别验证，队列和日志尾有界。清理超时记录终止未确认，继续关闭UART；不报告资源回收成功。

## 帧关联与可信显示

采集/解码帧接收、PS提交、PL接受SOF、屏幕扫描与曝光是不同事件。选择先于帧接收的历史快照，保存frame_id、epoch、原始寄存器、时间括号/不确定度和年龄，后续可重算。不能只因字段都有时间戳就说同步。

本案例在首行18像素提交历史帧元数据，生产链解析后显示历史速度/距离/里程/方向；最新风险边框/STOP/实际LOCK独立。坏标记、未来或过期时间撤销历史数值有效，历史状态永不续安全租约。格式/重复帧/实际SOF身份计数可用于诊断，但不证明显示器已扫描输出或曝光到屏幕延迟。

若要在网页看到PL叠加后画面，必须有相应回写/捕获路径；PS先写入的帧不会自动变成OSD输出。没有链路时明确网页仅显示状态/原图，避免无依据增加第二写回通路。
