# 可复用任务与交接模板

模板用于组织事实，不自带任何硬件/发布/外部消息授权。替换项目、基线、范围和判据后使用，已有当前目标时省去无关项。属于本次新整理的模板，未宣称这些精确文字经过陌生队伍实战验证。

## 实现一项功能

```text
请在给定项目内完成这项功能：<用户可见行为与输入/输出>。
根目录：<绝对路径>。当前权威契约/源码：<路径与版本>。
允许修改：<本次模块和必要消费者>。保留：<真实不变量/历史产物>。
先确认最小生产数据流、接口单位/事件/故障和可执行完成判据；
再实现并运行受影响的回归，跨层变化必须验证实际生产消费者。
不要通过删需求、默认填标定、改期望或使用旧日志完成任务。
输出实现/验证/未验证状态、原始证据、新版本影响和下一步条件。
```

## 串口或硬件故障定位

```text
现象：<观测和频率>。硬件/固件/连接：<实际版本与接线>。
已完成对照：<步骤、日志与结果>。当前可操作范围：<说明>。
请先分清供电、下载/调试与运行通信路径，用最小停止固件或只读测量
设计一次只改变一个变量的对照；区分硬件错误与协议错误。
不猜接线/料号，不把同一方向通信当成双向通过。
给出支持的定位范围、排除项、下一项最有判别力的测量与停止条件。
```

## 只读审查与复验

```text
审查给定当前候选：<契约、包、来源、允许读取路径>。
只读权威源码；临时反例写独立目录，不操作板卡/串口/电机。
围绕这次改变和未闭合风险查找可重复反例，优先跨层数据/故障传播。
先确认反例进入目标路径与正确预期，区分产品缺陷、测试器错误、
文档漂移和待测硬件项。引用真实退出码、原始日志和证据身份。
已修问题独立复验；没有新变化或存活风险就收束，不按固定轮次堆审查。
```

## 接口或时序优化

```text
目标：<功能/时序/资源改进>。现有基线：<身份与同条件指标>。
保持语义：<单位、定点精度、饱和/舍入、批次和时间事件>。
请从实际报告/路径/网表定位，提出最小可解释改动。
接口变化同步升级全部消费者与验证；流水变化逐拍验证数据/故障/序号配对。
比较功能、吞吐、总延迟、资源和整机时序，不降低规则严重性来消警告。
给出可复现前后证据和仍未验证的系统/物理范围。
```

## 交接

```text
目标与当前状态：<已实现/已验证/待测>。
权威版本与改动范围：<源码/契约/包身份>。
实际验证：<命令、退出码、条件、证据路径>。
已关闭问题：<最小反例与复验>。
剩余：<具体缺口；不要把硬件未测归为代码失败>。
接续动作：<最先可完成的一步与进入条件>。
构建/运行入口：<当前唯一入口；历史包不可混用>。
```

## 新项目迁移

```text
用此skill的通用方法推进<新项目>。先建立本项目的板卡/工具链、
需求、物理接口和权威契约事实表，不复制旧PYNQ-Z2管脚、SCALE、
UART格式、风险阈值或当前候选状态。给出最小跨层竖切与验收方法，
明确每个新建议需怎样验证；只执行本次授权任务。
```
