# v0.11 完整控制台 r16：红外只提示

日期：2026-10-26。用户确认：红外障碍、失效或断线均只提示，完全不参与停车判断。本轮只在电脑本地修改、验证和构建，没有切换小车网络、连接车载服务、部署或发送实车运动指令。

## 功能与策略

完整控制台保留驾驶总览、原图与 PL 图、传感器与双轮标定、记录与回放、六阶段演示。新增独立红外提示，区分障碍、无障碍、失效、历史数据和断线；真实红外数据仍回传、记录、显示。

FPGA 风险核、PS 控制监督器和 STM32 电机策略一致排除红外停车及解锁门槛。红外独立序号回退只标记红外失效，不丢弃同一报文中仍有效的超声波和执行器反馈。完整服务启动就绪不要求红外有效。独立传感器健康验收仍报告红外故障，不将其伪装为健康。

超声波近障和失效、编码器故障、控制命令有效期、串口租约、手动停车、松手、失焦和断链保护继续生效。SCALE 0 / 0 仍表示双轮未完成实测距离标定，不能绕过或填入假值。

用户随后要求按既定方案计算系数。已复核 2026-09-19 的配置：1:48、13 线、四倍频、名义轮径 65 mm，得到每圈 2496 计数，左右 SCALE=5362（0x14F2）。方案保存为包内 `desktop/nominal_scale_plan.json`，标记 measured=false、未写入硬件，不改变现有方向配置和实测驾驶许可。

连接助手现在拒绝旧“受限试跑”服务和未声明红外只提示策略的旧完整服务，避免打开旧页面并显示连接成功。关闭与离线本地入口保持可用。

该语义变更升级接口为 v0.11 / 0xC425100B，必须使用同一构建来源的 bit/HWH、STM32 固件和运行软件。仅更新前端无法改变旧硬件停车策略。
