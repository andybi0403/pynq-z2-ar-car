# 摄像头解码帧与历史显示状态同行传输

2026-09-30：传输模块已接入联合运行器及生产包装层；契约升级v0.9。新版整机bit/HWH/包尚未重建，未运行实板。独立模块与生产链路验证只能证明RTL流/软件行为，不能作为HDMI物理扫描或曝光延迟证明。

方法：在PS提交VDMA之前，将帧接收时选定的历史快照编码到第一行前18个BGR0像素。RGB888 AXIS保持这18个24位字；PL `car_axis_frame_metadata`暂存18个像素、验证格式及异或校验，发布历史显示状态，再重放原始SOF/EOL。这些有效标记像素被替换为黑色，后级OSD覆盖顶部保留区，其余像素原样通过。只有72字节的PS保留区域和18像素的PL缓冲，不新增整帧缓存或MMIO发布队列。

VDMA重复旧帧时也重复同一标记；跳帧时状态随被选中的帧一起跳过，不靠FIFO先后顺序猜帧身份。帧ID32位、快照epoch16位及估计PL接收时刻64位共同标识。生产包装层以同一64位PL时基检查帧接收年龄；未来或达到200ms时历史数值无效。帧身份/epoch/时间在中央描边模块接受SOF时提交诊断，所有历史显示行共享这个时刻锁存的有效性；TAG_COUNT用于主机组读复核，重复帧没有新接收时间。

2026-10-01新增中央描边与厘米标注，见 FRONT_OVERLAY.md。包装层增加第四帧过期重放与下游停顿跨越有效期的反例。构建状态以 latest_candidate.json 为准；实板验证仍待完成。

| 字序号 | RGB888字内容 |
|---|---|
| 0 | 固定magic `D3A95C` |
| 1 | 格式版本/字数 `010012`，独立于寄存器契约版本 |
| 2 | frame_id低24位 |
| 3 | snapshot_epoch16位、frame_id高8位 |
| 4 | 距离bit11:0；distance_valid12、speed_valid13、odometry_valid14；历史risk_level16:15、risk_stop17；23:18保留0 |
| 5—6 | 有符号32位双轮平均速度Q16.16，低24位先传，高字未用位为0 |
| 7—9 | 有符号64位双轮平均位移Q16.16，低24位先传 |
| 10—12 | 无符号64位双轮平均累计路程Q16.16，低24位先传 |
| 13 | 历史risk_reasons低16位，其余0 |
| 14—16 | 估计解码帧接收PL时刻64位，低24位先传 |
| 17 | 前17字异或再异或`FFFFFF` |

64位末字只用低16位，其他为0。所有字映射为DDR中的B,G,R,0四字节；解析端字值为AXIS[23:0]。异或校验检出单字篡改，不保证检出多字抵消错误，也不是密码学认证。完整日志另有SHA256和原始关联回放核验。

历史距离/速度的有效位同时检查原始META与关联时刻年龄；US故障撤销距离有效。里程按META有效/故障判断，其TS是最后边沿时刻，静止时不以边沿年龄使里程过期。无效风险快照显示FAULT和停止。风险安全决策与实际STM32 LOCK仍使用独立的最新数据，不能让历史帧控制电机或续驾驶租约。

解析器在坏格式、保留位、校验、短首行或非SOF开始时设置metadata_valid=0、撤销数值有效位并饱和累加header_errors。不能使用残留数值而忽略metadata_valid。缓冲不足18个像素时等待上游，等待不涉及传感器/控制数据面；整机还需视频失联监测。接口背压期间所有输出字段稳定，SOF输出前已提交本帧元数据。

独立测试包含负速度/位移、64位时刻、不同帧ID、坏校验、无标记、短头、随机生产停顿与输出背压、全部非保留像素/SOF/EOL比对。生产包装层TB额外发送三帧640×480画面，包含两组不同历史状态及重复帧；中途改变最新风险和实时速度/距离不改变已锁存帧。像素输出与两套独立数字/字符串参考合成图逐点比对，并核对AXI诊断、过期/未来/64位年龄饱和。解析输出与基础字模之间增加一个弹性像素流水级，防止18路前缀选择直接串接字模组合路径。后续仍需完整回归、整机布线与实物测量。
