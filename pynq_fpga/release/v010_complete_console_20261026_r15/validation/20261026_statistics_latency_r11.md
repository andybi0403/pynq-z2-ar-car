# r11：修复随运行时间增长的视频统计开销

沿用 r10 的接线说明、生产 FPGA bit/HWH、STM32 固件和原生编解码库。电机保持连接，仅允许锁车与零输出诊断。

长测发现：VideoHub.stats 在五个最长 7200 项的事件队列中逐项读取时钟，持有视频发布锁的时间随队列增长。实板满队列微基准旧实现中位约 202.5 ms；单次时钟加有序队列二分计数约 33.0 ms。同一份原始事件仍参与统计，没有删掉损坏帧、放宽时效或忽略协议拒收。

修复：一次统计使用同一个单调时间截点，复制有序时间队列后用 bisect_left 计算近 60 秒数量。完整队列及截点边界回归覆盖统计正确性；174 项 Python 测试通过。桌面连接器另修复冷启动等待时间和连接失败后恢复原 Wi-Fi，5 项网络恢复回归通过；这些 PC 工具不属于板端 manifest。

r10 前四轮和额外浏览器补测保留全部证据。实际 Edge 登录、原图、PL 图、同帧冻结及断开重连通过；电脑恢复 SEU-WLAN。r10 长测中的采样超时和少量协议拒收均保留，5 fps 对照没有改善，已恢复原自动模式。

r11 构建时实板复测尚未开始，完整联合验收为 PENDING。启动检查中的 QEI 未转动/未标定、IR=3 等状态仍真实显示，SCALE=0，不发送解锁或运动指令。后续实板证据单独登记，不修改本候选。
