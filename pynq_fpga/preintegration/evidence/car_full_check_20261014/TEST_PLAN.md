# 2026-10-14 整车台架检查计划

用户需求：完善既有 Edge 操控界面，提供桌面入口，排查已连接摄像头但提示未连接，并执行一轮实际接线后的系统检查。

基线为 `v010_stm32_sensors_20261013_r3`，契约 `0xC425100A`。编码器经 PCB 接 PYNQ，超声波和红外接 STM32，JB9/JB10 为板间 UART。用户确认所有接线已完成，但逐根电气与运行结果尚未验收。

| 顺序 | 检查 | 通过依据 |
|---|---|---|
| 1 | Windows USB 枚举、板端启动与登录 | 实际 FTDI 串口、板端系统与设备清单；不把断电或传输故障写成摄像头缺失 |
| 2 | 板端版本与运行占用 | 当前包哈希、bit/HWH、PL ID；摄像头、UART 和 MMIO 没有重复所有者 |
| 3 | 摄像头 | USB VID/PID、uvcvideo、V4L2 节点、协商格式和实际 JPEG 采集分别留证 |
| 4 | 板间 UART 与传感器 | 115200 的 Q1/S1 有效回传；US/IR真实序号与年龄；左右遮挡与目标距离变化 |
| 5 | 编码器 | 左右手转分别影响对应原始计数；静止不虚构速度；未完成轮尺度标定保持无效 |
| 6 | Edge 显示与停车链路 | 原图、真实 PL 处理图、同帧冻结；断链数据清空；STOP 后收到真实 STM32 锁车零输出 |
| 7 | 联合运行与故障检查 | 就绪后先30秒；实际条件齐备后1800秒。各故障场景独立保存，清理后再启动 |
| 8 | 桌面交付 | 明确使用 Edge 的控制台快捷方式；入口读取当前会话，不沿用旧令牌或缓存页面 |

台架程序要求电机动力物理断开。未确认该条件前，只执行USB、启动与摄像头枚举等检查，不伪造 `--motor-disconnected`。当前版本没有非零电机驾驶/释放支持；运动验收单独进行。

界面变更属于运行代码，需执行有意义的页面断链回归并生成新同源候选；不改写已冻结旧包。原始日志、失败和待测项目都保留。

开始时 Windows 只发现蓝牙COM3/6/7/8，既有PYNQ FTDI设备为非当前连接。用户随后确认刚才板卡未开机；后续结果以上电后的重新检查为准。

本轮远程可执行的检查已结束。新候选构建/部署、摄像头、板端HTTP、无线网页出图、同帧冻结与一小时纯视频已留证；STM32开机提醒后的最终串口重测仍0字节，QEI有非法跳变和里程故障，物理刺激、标定、实际停车及正式联合运行未具备条件。桌面Edge入口已交付，电脑恢复校园网、临时服务器停止、板端资源关闭。完整结论见同目录 `TEST_REPORT.md` 与 `TEST_SUMMARY.json`，不能将纯视频通过升级为整车通过。
