# 前方描边与中文数据显示

生产路径为帧标记解析 → 弹性像素级 → 中央区域描边 → 风险/速度/距离 → 车辆状态 → 视频输出。无线版本为 1280×720，处理区域 x=320..959、y=180..539；640×480 版本为 x=160..479、y=120..359。

中央不绘制固定虚线框，只保留图像轮廓。使用上一完整帧轮廓的最小 x、最小 y，将前方测距标注放在描边范围左上方；位置在下一帧开始时锁存，有一帧位置延迟。右侧和上方限制位置，避免标注超出屏幕。上一帧没有轮廓时隐藏标注；轮廓消失后最多再保留一帧位置，不保留过期测距数值。

左上角字高由 8 增到 16 像素，使用中文标签、深色底和明确单位：速度 mm/s、距离 mm、路程 mm、位移 mm。原因码与故障码明确显示 0x 十六进制，锁车显示是/否，方向显示正/反/停；缺失或无效数据显示无效。速度距离分别在 y=24、48，附加状态从 y=80 起每 24 像素一行，x=24。

字模为 Noto Sans SC 固定 16×16 单色子集，生成入口 fpga/scripts/generate_osd_font.py --font <font>；原字体 SHA256 及字形表见 fpga/rtl/font_16x16_hud.json。字体遵循 SIL OFL 1.1，许可证随字模和部署包保留，不沿用项目代码许可。

灰度为 (R+2G+B)/4，3×3 Sobel 的 |Gx|+|Gy| 达到 160 时描边。窗口中心 (x-1,y-1) 的边缘画在输入 (x,y)，有右/下各 1 像素相位；处理区域内保留 2 像素边界。描边及主体标注统一绿色，几何颜色不代表安全。风险移至右上角三个直径 48 px 的圆灯，下方 32 px 中文为安全、注意、紧急；仅当前状态实心，其余灰色空心。最新状态在接受 SOF 时锁存，风险 0/1/2 对应绿/黄/红，风险 3、STOP 或速度/距离无效选择紧急红灯；不会用显示颜色改变控制判定。取消旧外框和左上角状态小块，无效附加数据用灰色并明确显示无效。

这是图像梯度轮廓，会包含纹理与阴影，没有对象分类、逐物体深度或语义主体识别。超声波测距属于前方传感器，不代表画面中特定物体的距离；显示 floor(mm/10) cm，不能据此声称厘米级实测精度。

验证采用生产 RTL 全帧逐像素对照、源停顿/输出背压/复位、全部 4096 个距离输入及生产包装层的历史帧/重复帧/过期帧检查。实板图像、测距、性能及联合验收分别记录，仿真通过不替代实测。

中文字体的单周期选择与查表之间加一拍弹性流水，输出背压时字形和像素一同保持。无线视频驱动以两份相同输入触发 S2MM 下一 SOF 完成通知，第二份写入独立 scratch 缓冲；仅在首帧完成、发送停止、接收停止且无 DMA 错误后交给编码器。该缓冲不进入编码队列，分配 7 个帧缓冲，避免相邻事务或编码线程互相覆盖。
