# 接口契约 v0.9：统一生产候选顶层

更新：2026-09-30，Codex。v0.7新增PL双轮物理里程，v0.8新增实际STM32状态与完整OSD，v0.9新增随视频同行的历史帧状态及帧身份/年龄诊断。新增候选尚未完整重建、未上板。历史交付包保留用于追溯；新主机拒绝旧契约ID。

## 时钟、时间、数据有效性

- 单一100MHz时钟，同步高有效复位；1 tick=10ns。64位公共自由计数器。
- 200ms=20,000,000 ticks；150ms=15,000,000 ticks；250ms=25,000,000 ticks。原20000 tick=200ms为错误。
- 32位时间约42.95秒回绕。年龄统一使用完整32位无符号差值，比较窗口须小于半个模周期；不得再把valid塞进时间最高位，也不得混用不同位宽或时钟起点。
- PS monotonic与PL tick不是同一起点。主机必须明确建立时基对应和不确定度；不能直接相减。
- sample_ts记录采集/观测完成，seq只在真实测量或完整无边沿观测窗口发布时增加。读取、重复快照、UART心跳不更新sample_ts。
- valid与age必须同时检查。传感器失效、异常、配置变化可能立即降valid而不创造一个新有效测量。
- 视频video_sof_ts只表示SOF到达PL，不是摄像头曝光时间。

## v0.9生产候选接口

- 生产候选顶层：`car_perception_top`；ID为`0xC4251009`。
- 只有一个64位100MHz时基、一个AXI-Lite从机和一次全局快照；US、IR、QEI0、QEI1、风险和命令各保留自己的时间、valid和seq。
- 唯一寄存器源为`fpga/registers/register_map.json`，由生成器输出`fpga/rtl/car_reg_defs.vh`、`host/car_regs.py`和`nightly/register_map_v0.9.md`。三个生成文件禁止手改。
- 地址区为公共`0x000—0x03F`、传感器`0x040—0x07F`、QEI`0x080—0x0BF`、风险`0x0C0—0x0FF`、配置`0x100—0x1FF`、里程`0x200—0x27F`、显示`0x280—0x2DF`。精确位图以生成表为准。
- `CTRL.bit0`触发全局快照，`SNAP_EPOCH`每次成功锁存加一。主机写触发后须观察epoch变化，读取所有字段，再确认epoch未变。
- 风险原因位：0禁用、1命令无效、2命令租约过期、3/4超声无效/过期、5红外无效、6保留（IR变化时间不得用于周期过期判断）、7红外障碍、8/9双QEI无效、10/11双QEI过期、12动态距离、13轮速方向异常。
- 风险核以九周期流水发布同批`required_mm/state/reasons/sample_ts/seq`；前进命令下轮速必须按配置归一为正，负值按方向故障锁停。它不替代STM32最终锁存。
- `car_axis_osd`为纯AXI4-Stream RGB888核：TUSER=SOF、TLAST=EOL、状态只在已握手SOF提交、背压时输出保持。距离valid与速度valid分别来自US和QEI影子，不得合并成单一传感器valid。它与安全判定单向隔离。

双轮里程均按每个合法x4边沿累加对应SCALE：有符号64位Q16.16位移随反转减少，无符号64位Q16.16路程只增加。SCALE复位0时无效；显式ODOM_CTRL.bit0清零双轮，SCALE/方向/滤波变化重置对应轮并递增16位epoch。非法AB跳变使里程持续无效；数值溢出饱和并锁存fault；非法计数诊断饱和后必须硬件复位，不能仅清里程解除。TS只在边沿/清零/首次故障更新，静止里程不能套用周期传感器的年龄过期条件。各轮高低字、TS、META、epoch在同一次CTRL.bit0快照锁存；主机读完全部字段后再次核对SNAP_EPOCH。车辆位移/路程为左右均值，两轮都有效才有效。

`host/calibration_config.py`保存左右前轮映射、SCALE、方向、滤波、零速观察窗及测量来源，禁止自动套用名义标定。加载需显式断开电机，先撤销命令、清两路SCALE，写配置后逐项读回；失败清两轮SCALE。风险参数是编译常量，来源随`source_contract.json`及交付清单记录；修改必须重建。构建输入变化或缺少bit/HWH来源绑定时拒绝打包。

显示发布与风险控制单向隔离：唯一MMIO所有者收到新的有效CAR序号时，先写DISPLAY_CAR_AGE（接收至当前的年龄），再以完整WSTRB写DISPLAY_CAR_STATE提交LOCK/FAULT与时间。700ms总年龄到期后失效并保持失效，32位时间回绕不得复活旧反馈。不能反复发布同一回传来续期。OSD新增M累计路程、D有符号位移、R风险原因十六进制、L实际LOCK与F实际故障十六进制、P测量方向；里程超过8位十进制显示范围或无效时显示F。所有状态在已接受SOF锁存。DISPLAY_FRAMES只数流式显示SOF，不是摄像头帧身份，不能据此声称曝光到显示已对齐。v0.9的历史帧提交与诊断规则见下文；曝光到显示偏差仍待实测。

v0.9视频传输：PS提交前在首行18像素中编码所选帧的ID、epoch、估计PL接收时间与历史数值。生产包装层先解析，再经可背压像素流水级进入双OSD。速度/距离/里程/位移/方向及R历史原因来自该帧；风险边框/STOP提示和STM32 LOCK/FAULT来自最新独立数据，并在各自SOF锁存。历史状态不能写回安全控制或续租。标记缺失/错误、未来时间或距当前PL时刻已达200ms撤销历史数值有效；普通未打标记的视频仍可流过，但数值显示无效。估计接收时间不是曝光时间。

DISPLAY_FRAME_ID/STATE/TS/AGE描述已被基础OSD接受的SOF。STATE bit0是格式有效，bit1是64位年龄新鲜且不在未来，epoch在31:16；AGE以100MHz计数，超32位或未来时间饱和。TAG_COUNT提供诊断组读前后复核；REPEATS只计帧ID与64位接收时间均相同的重复，HEADER_ERRORS是坏标记饱和计数。它们证明PL流中帧身份，不证明HDMI显示器已扫描输出。完整字序见`preintegration/host/FRAME_METADATA.md`。

DISPLAY_FRAME_SOF_LO/HI记录基础OSD接受该SOF的实际64位PL时刻，与FRAME_TS相减可测估计接收至进入叠加的时间。联合日志按控制轮询采集，因此可以漏掉中间SOF，只统计观察到的不同TAG_COUNT/SOF时间组；不能声称逐帧曝光或扫描输出延迟。独立审核同时绑定帧ID/epoch/接收时间与提交日志，缺身份、坏标记、过期或SOF早于接收时刻不能通过实板门禁。

以下v0.5表格继续描述三个模块验证包装层，只用于回归和追溯。新主机与夜间任务必须读取v0.9生成寄存器表，不得用这些包装层地址访问统一顶层。

## AXI-Lite与公共寄存器

12位字节地址，32位数据，按字访问。`ID_VERSION[31:16]=0xC425`，`[15:8]`是模块类型，`[7:0]`是契约版本。前端直接复用verilog-axi固定提交的axil_reg_if。AW/W独立握手；全部写操作遵守WSTRB。CTRL只有WSTRB[0]=1才触发。非法地址读0/写忽略，响应OKAY（当前明确限制）。

| 偏移 | 名称 | 语义 |
|---|---|---|
| 0x000 | ID_VERSION | 见上表 |
| 0x004 | CTRL | WO bit0=快照触发；bit1=64位时间锁存 |
| 0x008 | STATUS | bit0=快照done；bit1=时间锁存done；复位值3 |
| 0x00C | SNAP_ERR_CNT | 无效快照次数，16位饱和；QEI任一路无效即计一次 |
| 0x010/014 | TS_LIVE_LO/HI | 调试实时值，分次读取可能撕裂 |
| 0x018/01C | TS_SNAP_LO/HI | CTRL.bit1锁存同一拍64位时间 |
| 0x020 | SNAP_DATA | 单生产者数据；QEI兼容别名为通道0速度 |
| 0x024 | SNAP_TS | 完整32位sample_ts，复位0 |
| 0x028 | SNAP_META | [31]valid；[15:0]seq；中间保留0 |
| 0x02C | SCRATCH | RW，复位0xA55A5A5A，逐字节写 |

写触发后轮询done，再在下一次触发前读取完整影子组。生产者用live_update将四元组提交到内部committed bank；没有live_update的总线变化不可见。trigger与live_update同拍时提交的新批优先，否则只读取上一批committed数据。生产者在某沿用非阻塞赋值同时改变数据和live_update时，下游在下一沿看到该提交脉冲；禁止声称同一沿直接可见。

## 超声波与红外寄存器

| 偏移 | 名称 | 语义/复位 |
|---|---|---|
| 0x030 | US_DIST_MM | live，[11:0]mm，[15:12]fault；高位0 |
| 0x034 | US_SAMPLE_TS | live，完整32位采集时间 |
| 0x038 | US_SEQ_ERR | live，[31:16]饱和err，[15:0]seq |
| 0x03C | IR_STATUS | bit0左障碍，bit1右障碍，bit2稳定；原始低有效已转换 |
| 0x040 | IR_TS | 最近状态/稳定标志变化的真实公共tick，不是变化次数 |
| 0x044 | US_CTRL | bit0 enable，复位1 |
| 0x048 | US_META | live，[31]valid，[15:0]seq，中间保留0 |
| 0x04C | IR_FILT_TICKS | 稳定窗口，复位5000=50us；0为同步后的旁路 |
| 0x110 | US_CFG_PERIOD | 测量完成后空闲间隔，复位6,000,000=60ms |
| 0x114 | US_CFG_MAX_ECHO | 每个等待阶段超时，复位3,000,000=30ms |
| 0x118 | US_CFG_TRIG_CLK | 复位1000=10us |

- 正常采样间隔为60ms空闲+10us触发+响应等待+Echo宽度+少量流水拍，**不是严格60ms触发到触发周期**。两个等待阶段都到30ms时，最坏故障发布间隔约120.01ms，为200ms控制数据过期留下约80ms的软件与传输余量。真实模块响应与PS/UART预算仍需系统测试。
- 每次进入测量时锁存TRIG宽度与Echo超时；测量中AXI改配置只影响下一轮，不能改变正在进行的脉冲或截止点。空闲间隔允许下一轮读取新值。
- 0配置停止测量并降valid；不能把无符号减1下溢当无限等待。
- 距离换算K=round(343/200000×2^32)=7365869，乘K后右移32；输出向下取整。输入脉宽超过4m对应上限2,332,361 tick判超量程。
- fault：0正常、1无回波/禁用、2卡高、3超量程；异常计数根据本次判定增加，不能使用上一拍fault。
- 正常sample_ts在同步后的Echo下降沿识别时锁存，数据下一拍发布。相对物理引脚还含同步器延迟，不能声称物理采样误差≤1tick。
- 公共SNAP_*只代表超声波，IR变化不得刷新US年龄或把US无效改为有效。IR_TS是变化时间，静态输入不更新，不得把它直接当连续采样的新鲜度依据。
- live寄存器仅调试；控制消费距离优先读SNAP_*。IR变化信息独立读取，系统集成时补联合快照或明确安全优先覆盖。
- 断线固定电平与真实静态状态无法仅凭此RTL区分；硬件上拉/电平转换待测。

## QEI与周期法速度（候选）

正向cfg_dir=0：00→10→11→01→00。cfg_dir=1反向。两级同步后对AB组合做可配置稳定窗口。上电等待同步稳定再采纳初始AB，不凭初始10/01虚构一个计数。配置变更重新建立相位基线，运行中不应改变方向或滤波。

双位跳变不计数，非法计数8位饱和并重同步。合法跃迁x4计数，位置32位自然回绕；PS位移用int32差分，前提单次差值不超过有符号范围。静态绝对距离不是位置计数器本身。

| 偏移（路0/路1） | 名称 | 语义 |
|---|---|---|
| 0x120/138 | POS | 最近速度批关联的位置，快照影子 |
| 0x124/13C | INFO | 快照时诊断：[0]当前方向；[1]曾见合法沿；[2]当前period_valid；[11:4]非法累计；[19:12]除法重启累计低8位；[27:20]滤除累计 |
| 0x128/140 | PERIOD | 最近速度批使用的相邻同向边沿间隔；零速观测批为0 |
| 0x12C/144 | VEL | 有符号Q16.16 mm/s |
| 0x130/148 | VEL_TS | 速度批观测时间低32位 |
| 0x134/14C | VALID_SEQ | [31]valid，[15:0]seq；中间保留0 |
| 0x150/154 | POS_LIVE | 当前累计位置，仅调试（新增） |
| 0x160/174 | CFG_DIR | bit0方向取反，复位0 |
| 0x164/178 | CFG_FILT | 稳定窗口tick，0旁路，复位0 |
| 0x168/17C | CFG_SCALE | **unsigned Q16.16 mm/轮轴x4计数**；复位0=未标定无效 |
| 0x16C/180 | CFG_SHIFT | 保留，必须为0；非零使速度无效 |
| 0x170/184 | ZERO_TIMEOUT | 无边沿观测窗口，复位10,000,000=100ms；小于66非法 |

0x11C不再定义；旧v0.3的SCALE/SHIFT/更新窗口含义禁止沿用。两路全部影子由一次CTRL.bit0同时锁存，分别保留seq/time/valid；两路同拍完成不会丢一路。POS/PERIOD/VEL/VEL_TS是同批；INFO是锁存时诊断，不能反向冒充该速度批的方向。

比例系数由已核实轮周长与CPR标定：scale=round(轮周长mm/输出轮一圈x4计数×65536)。13电机轴PPR不能直接当52轮轴CPR。生产默认scale=0；测试scale=65536只是假设1mm/count。

2026-09-19编码器核定补充（依据`docs/03_硬件与接线/10_霍尔编码器TT马达电气与QEI参数核定_20260919.md`）：编码器为霍尔编码器TT马达，电机轴13线，x4合法跳变计数，输出轮一圈x4计数=13×减速比×4：1:48为**2496**、1:90为**4680**。项目当前配置为`TT_48_ORIGINAL_WHEEL_FRONT_2`（1:48双前轮、原装轮胎、65mm粗测），QEI0=左前、QEI1=右前。四组资料对照预设（计算器`pynq_fpga/host/qei_calibration.py`与单测为准）：

| 减速比 | 轮径 | x4计数/轮 | SCALE十进制 | SCALE十六进制 | 性质 |
|---|---|---:|---:|---:|---|
| 1:48 | 60mm | 2496 | 4949 | `0x00001355` | 资料对照 |
| 1:48 | 65mm | 2496 | 5362 | `0x000014F2` | 当前profile临时值（65mm粗测，未带载标定） |
| 1:90 | 60mm | 4680 | 2640 | `0x00000A50` | 资料对照（厂家STM32例程） |
| 1:90 | 65mm | 4680 | 2860 | `0x00000B2C` | 资料对照（厂家Arduino例程） |

5362只能由PS在显式选择profile后经`configure_qei_scales/configure_qei_profile`写入并读回验证；生产复位SCALE仍为0=未标定无效，任何名义值不得成为RTL或寄存器复位默认值。带载滚动周长标定后以左右实测值分别重算替换。

PL计算：magnitude=floor(scale×100,000,000 / period_ticks)，方向施加符号后饱和到[-2^31,2^31-1]。主机只设置标定常数，不计算实时速度。标定乘积流水准备，64拍恢复除法；配置变化撤销未完成计算，新标定稳定后才接收边沿。

首次边沿、反转的首沿、非法跳变及周期计数溢出均不发布有效速度；后续两个连续同向边沿恢复。小于66tick的周期因吞吐预算判无效。普通64拍计算期间继续保留上一完整批的valid与时间戳；若新边沿早于计算完成，则增加overrun、撤销旧valid并从最新周期重启，不能静默丢边。实际允许最大速率须结合滤波设置和整机约束。

无边沿持续ZERO_TIMEOUT后发布零速有效观测；此后每完成一个完整无边沿窗口才产生下一批零速观测，读取不刷新。静止不等于硬件连接已被验证；断线诊断仍是硬件/系统任务。

位移候选：delta_count=int32(pos_new-pos_old)，delta_mm=delta_count×已标定mm/count。任务4不提供绝对里程累计寄存器。

## 风险、视频及集成边界

PL测速、风险核、OSD和统一顶层均为可验证候选，不代表已冻结实物参数。生产架构固定为一个统一感知顶层、一个64位时基、一个AXI从机和一次全局shadow快照；三个旧`*_top`只用于模块回归。现有仿真/OOC综合不等于完整PYNQ Overlay、DDR/VDMA/HDMI或实物安全验收。后续接口变更必须递增版本、更新机器源与本契约并重跑所有消费者。
