## 实际架构

```text
C270 UVC → PS/FFmpeg解码缩放 → DDR BGR0三缓冲
                                  │
                                  ▼
PS S_AXI_HP0 ← VDMA MM2S → AXIS 32→24 → OSD占位槽
                                      → AXIS-to-Video → VTC → RGB2DVI → TMDS

PS M_AXI_GP0 → VDMA / 控制占位槽 / dynclk / VTC / HPD GPIO
VDMA MM2S中断 + HPDN中断 → concat → PS IRQ_F2P
```

控制占位槽位于`0x43C00000/4KiB`，只用于证明控制地址和总线边界，ID为`0x534C4F54`，不能冒充生产`car_perception_top`。VDMA位于`0x43000000/64KiB`；dynclk、VTC、HPD GPIO分别位于`0x43C10000`、`0x43C20000`、`0x41230000`。

## 带宽和像素格式

DDR固定使用每像素4字节的little-endian `BGR0`，stride为2560字节；24位RGB只存在于VDMA后的AXIS侧。640×480@30的单次帧载荷为36.864 MB/s。按PS解码写、主机复制读、DMA缓冲写和VDMA读四次搬运，保守预算为147.456 MB/s。这个数是预算，不是板上测得吞吐。

## 电气与开源核对

- HDMI管脚来自`pynq-z2资料/引脚约束文件/pynq-z2_v1.0.xdc`第177—188行。
- `TUL_PYNQ Schematic_R12.pdf`第6张图显示HDMI pin 19经Q8和R158形成`HDMI_TX_HPDN`主动低输入，因此R19按`INPUT/LVCMOS33`约束；没有沿用旧Base Overlay的输出方向。
- 实现IO报告确认HPDN为R19输入，TMDS使用L16/L17、K17/K18、J19/K19、H18/J18。
- 直接复用官方`Xilinx/PYNQ`固定commit `e054c09c52db3244ef35c8ae08a2e62c1e4955fd`中的`axi_dynclk`、`rgb2dvi`、接口定义和PYNQ VDMA驱动调用，许可证为BSD-3-Clause；登记见`pynq_fpga/OPEN_SOURCE_USAGE.md`。
