# PYNQ-Z2 LAB_ONLY无电机台架包交接

Status: READY_FOR_HARDWARE

日期：2026-09-19。PYNQ实板预计约一周后到手；当前只声明离线产物和自动契约通过，所有实物栏保持未验证。

## 已完成

- 从完全布线的任务7/8生产核集成候选生成压缩bitstream。
- bit/hwh同名，统一ID`0xC4251006`；HWH确认生产`car_system`存在、两个占位核不存在。
- WNS `+0.079ns`、WHS `+0.027ns`、TNS/THS 0；写bit前DRC 0 Error。
- manifest记录bit/hwh字节数和SHA-256，包级`contract`命令已通过。
- 板端脚本支持七个阶段：`contract`、`mmio`、`sensor-check`、`uart-stop`、`safety-loop`、`color-bars`、`camera`。
- `sensor-check`逐样本核对US valid/fault/距离和IR valid/stable/mask，失败会保留首个原始寄存器差异。
- UART阶段必须显式传`--motor-disconnected`，代码只发送STOP和零速/无效心跳，不发送PREL或非零PWM；只接受STOP后新收到的`$CAR`并测量300ms门限。
- `safety-loop`把生产PL快照/风险、Python桥接和真实STM32新`$CAR`记录到同一时间线，仍只允许零速且要求电机物理断开。
- camera阶段默认验证≥25fps、P95≤50ms和估算掉帧率≤5%；色条只报告已提交，仍要求人工确认屏幕色序。
- release校验仍按预期失败，LAB_ONLY不会晋升为发布产物。
