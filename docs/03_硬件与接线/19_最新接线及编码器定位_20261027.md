# 最新接线及编码器定位（2026-10-27 回交）

依据：回交提交 `2e567bc72ea6d8c947a50aef588e9fd0c4501975`、[最新现场交接](../../handoff/20261027/returned/今日实机调试暂停交接_20261027.md) 与原始 JSON。本页更新使用入口，不改变旧设计和发布包。**正常接法、最后已确认临时接法和未执行计划必须分别看。**

## 正常运行接法

| 信号 | 连接 |
|---|---|
| J1.LA3/LB3/RA3/RB3 | 官方 JB1/JB2/JB3/JB4，FPGA W14/Y14/T11/T10 |
| J1.GND | PYNQ 可靠 GND |
| J2.OEN | JA9/W18，低有效；正常运行不永久接地 |
| J2.3V3 / GND | Pmod 3.3V / GND；本轮采用 JA12 / JA11 |
| J5.5ENC / GND | Arduino POWER J7.4（板上 5V）/ GND |
| 左编码器负/A/B/正 | J3.GND/LA5/LB5/5ENC |
| 右编码器负/A/B/正 | J4.GND/RA5/RB5/5ENC |
| PYNQ UART JB9 / JB10 | 扩展板实际丝印 TX / RX；不按普通模块命名再盲目互换 |
| 双板公共地 | 扩展板 GND→JB11（本次修正位置）；JB8 是信号针，不作地 |
| 扩展板蓝牙口 VCC | 不连接 PYNQ 正电源；S5 OFF、蓝牙模块不插，BOOT0=0 依据既有成功方案，接手仍核实现场 |

JA/JB 为 PMODA/PMODB 官方实体针号。5/11=GND，6/12=3.3V，不能根据从照片一侧数到的孔序改写编号。编码器电源需要实测到电机尾板，接到 5V 标签处不是电气验收。电机动力最外两根不经过绿色板。

超声波和红外仍由 STM32 采集；不恢复旧的直接接 PYNQ 方案。两侧电源正极不并联，PYNQ 输入不直接承受 5V。

## 最后已确认的现场与待核实项

17:20 原 LA3 输出线的 PYNQ 端仍在 JB1，绿色端临时由 J1.LA3 移到 J3.GND；JA5→LA5 临时线两端已取下；两组编码器输入隔离。其余 J1/J2/J5 保持原测试条件。17:23 安排关机，但物理无电未确认。

之后提出但没有完成回执、没有测试的是：恢复 LA3→JB1、JA5(GND)→LA5、从 JA9 完全断开 OEN 后临时接可靠 GND。不要假定现场已变成该接法，也不要在 OEN 仍连着 JA9 输出时并地。该动作仅是隔离台架计划，不是正常接线方案。

## 新证据带来的定位变化

| 通路 | 原始结果 | 支持的结论 |
|---|---|---|
| 独立线：J3.GND→JB1 | 32/32 读 0 | JB1 与该次 GPIO 读法能识别低电平 |
| 原 LA3 输出线：绿色端移至 J3.GND，另一端 JB1 | 32/32 读 0 | 该线到 JB1 的低电平路径通过；不包含 J1.LA3 针/焊点接触 |
| JA5 地→LA5→转换板→J1.LA3→原线→JB1 | OE 禁用/启用各 25 次均读 1 | 转换路径低电平未通过；需查输入接点、供电、地、DIR、/OE、焊接与芯片 |

故障优先级已经从“所有输入端都没正对照”推进到“转换板通路优先”，但仍不能单独认定 U1 或编码器损坏。JB2～JB4、高电平和动态沿尚未建立完整对照。

U1 按本设计为 SN74LVC245A：20=VCC、10=GND、1=DIR（接 3.3V）、19=/OE；左 A 输入 2→输出18，左 B 为3→17，右 A 为4→16，右 B 为5→15。封装/Pin1/实际料号必须先确认，丝印图和网表不能代替焊后测量。

具体测量及结束标准见 [今晚收尾顺序](../../handoff/20261027/02_今晚收尾顺序.md)。
