## 一、编码器硬件选型

**BST-4WD电机形态核实**：标准TT减速马达（130机芯+黄色齿轮箱+65mm TT专用轮），不是N20/GA12。证据：亚博官方课程页FAQ确认"TB6612驱动、同侧两电机共用一路PWM"；车主开源仓库4wdcar_stm32103的BOM为TT电机×4并自行加装光电码盘。

**实际采购（已确认）**：松甲科技霍尔编码器TT马达×2只装前轮，减速比1:48（13线霍尔AB相、PH2.0-6P、4.5V—5V、板载上拉）。早期调研的"亚博同形态替换品"候选路线被实际采购取代；下表保留为当时行情记录。

## 二、精度核算与测速方法（2026-09-19废止并改写）

**历史假设已废止**：本节旧版本基于"13PPR位于输出轮轴且65mm轮"的假设，推出"20cm/s→边沿率51Hz→M法10ms窗口0.5个计数不可用，优先T法"。该假设已由厂家手册证伪：**13线霍尔在电机轴（减速箱前），输出轮一圈为2496（1:48）或4680（1:90）个x4计数**，旧核算把电机轴PPR误当轮轴计数，结论全部作废。

**核定后的边沿率**（见10号文档第8节）：

- 当前profile（1:48、65mm粗测、2496计数/轮）：20cm/s → 边沿率约**2445Hz**，M法10ms窗口约**24.4计数**，计数充足。
- 附录对照（非本项目配置）：1:90、65mm、4680计数/轮 → 20cm/s约**4584Hz**，同样充足。
- 低速端仍由T法周期测量（PL已实现）和QEI零速观测窗口覆盖，x4边沿率提高约48倍后T法/M法均工作在更舒适区间；速度核按契约v0.6实现，低速可用性仍需上板实测，不在此宣称PASS。

**测速接口现状**：9月18日任务4已实现PL周期法速度核（相邻同向边沿周期→64拍除法→Q16.16 mm/s，双路原子影子寄存器），当前实现以**接口契约v0.6**（`pynq_fpga/nightly/interface_contract.md`）为准。本节旧版"(a)/(b)/(c)三选一候选"与"契约v0.4"表述已过时，仅作历史调研记录保留，不得再用于新开发。AMDC-Firmware（BSD-3）的"PL自由计数+trigger/done原子快照"仍是快照结构的参考来源。

## 三、正交解码器开源方案对比结论

20个资源核实后（完整对比表存调研记录），关键结论：

| 维度 | 最佳实践 | 采纳来源（许可证） |
|---|---|---|
| 解码核心 | **4状态FSM x4解码**（非法跳变锁存不计数+err脉冲可观测），优于fpga4fun XOR法（XOR会如实计数毛刺边沿） | AMDC-Firmware `ip_repo/amdc_encoder_1.0`（**BSD-3**，2026-07活跃，Zynq-7000平台，带testbench）+ OmarAlchikha相关候选（尚无精确仓库定位，许可证未核实，未并入） |
| 同步 | 2FF + `(* ASYNC_REG="TRUE" *)` | 全部高质量实现共识 |
| 毛刺滤波 | **参数化N-tick滞留滤波，0=旁路**；窗口必须≪最小边沿间隔（当前复位旁路；是否启用须测量电机噪声、线长和实际最小边沿间隔） | OmarAlchikha（仓库及许可待核实，未并入） |
| 计数 | 32位自由回绕，PS侧int32差分，PL不做饱和/清零 | AMDC |
| PS读取原子性 | **trigger/done双缓冲快照寄存器**（PS写trigger→PL锁存counter+时间戳到shadow→done→PS读），防撕裂——这是AMDC最值得抄的结构 | AMDC |
| AXI封装 | Vivado"Create and Package New IP"AXI-Lite模板（AMDC即此结构）；备选手写（alexforencich/verilog-axi `axil_reg_if`，MIT） | AMDC |
| 验证 | **cocotb**：复用alexforencich `axil.py`的AXILiteMaster BFM + 自写编码器激励driver（可编程频率/相位/毛刺注入，约50行） | alexforencich（MIT，2137星） |
| 测速 | 本轮已核实AMDC编码器模块不直接提供本项目所需周期法速度；本项目已实现PL候选，不能由有限检索断言GitHub不存在其他实现 | AMDC架构取舍 |

**排除项**：WangXuan95/FPGA-FOC（GPL-3.0，本项目当前复用范围不并入，且用AS5600无正交解码）；AdriaanSwan（GPL-2.0）；hwstar/bdcmotor（GPL-2.0）；OpenCores q_rotary_enc（死项目）；XLR8Quadrature（LGPL争议）；Xilinx PG139（本机未找到可直接采用的对应IP，未证明版本移除）。

**PYNQ生态核实（负面结论，对竞赛有利）**：PYNQ官方、PYNQ_Workshop、PYNQ_Peripherals（geared_motor只有PWM驱动无反馈读取）、PYNQ论坛均无现成编码器overlay/QEI IP——**有限检索不能证明不存在先例；创新性应由实际实现与比赛要求判断**。唯一PYNQ实战参考是Jan Cumps的element14博客（PYNQ-Z2+PmodB+Jupyter MMIO读正交计数，VHDL+GPIO方案，思路可借鉴）。

## 四、最终技术组合

```text
硬件（2026-09-19核定）：松甲霍尔编码器TT马达1:48，左前+右前2只；4套为历史扩展建议
  → SN74LVC245A（VCC=3.3V，输入5V容忍，DIR固定A→B，一片8通道；首版只用半片4通道）
  → Pmod B 1-4（首版2套）/ Pmod A 实体3/4/7/8=Y16/Y17/U18/U19（历史扩展期另2套，实体5=GND、6=3.3V）

PL QEI（首版2通道，参考AMDC结构，已实现于car_qei_core）：
  2FF同步(ASYNC_REG) → [参数化滤波，默认旁路] → 4状态FSM x4解码（err脉冲+err计数）
  → 32位回绕位置计数 → 边沿100MHz时间戳锁存
  → AXI-Lite寄存器：CTRL/STATUS(err)/POS_SNAPSHOT/TS_SNAPSHOT（trigger/done快照）

当前实现：相邻同向边沿周期 → 64拍除法 → Q16.16 mm/s；PS读双路原子快照与位置差分
  → 与超声波/红外一起进 $P 帧和风险状态机
```

## 五、验证计划（无板卡可做）

1. cocotb编码器模型：正交序列发生器（可编程频率/相位差/毛刺注入/方向反转）+ alexforencich AXILiteMaster BFM，回归断言：x4计数正确性、方向翻转、非法跳变err、快照原子性、回绕差分。
2. 极值用例：静止（无边沿）、单边沿抖动（A翻转回跳）、A/B同拍翻转、频率扫到100kHz。
3. 与安全状态机联测：位置差分→$P帧→STM32 RAW驱动闭环仿真。
