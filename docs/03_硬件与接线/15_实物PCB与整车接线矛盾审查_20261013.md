## 实际PCB接口，不是需求中的逻辑别名

以下均为现有编码器PCB的J编号，不是底盘或PYNQ的同名连接器。针1按方形焊盘确认，避免从图片左右方向猜针号。

| PCB实体接口 | 针序及用途 | 原计划连接 |
|---|---|---|
| J1 / OUTPUT | 1=LA3、2=LB3、3=RA3、4=RB3、5=GND | 1～4→JB1～JB4；5→PYNQ GND |
| J2 / CTRL | 1=OEN、2=3V3、3=GND | 1→JA9；2→PYNQ 3.3V；3→GND |
| J3 / 左输入 | 1=GND、2=LA5、3=LB5、4=5ENC | 左前轮编码器的四根逻辑线 |
| J4 / 右输入 | 1=GND、2=RA5、3=RB5、4=5ENC | 右前轮编码器的四根逻辑线 |
| J5 / 电源 | 1=5ENC、2=GND | 1→PYNQ Arduino POWER J7.4；2→GND |

网表确认：U1.2～5为四路编码器输入；U1.18～15分别连J1.1～4；U1.6～9（A5～A8）全部接GND；U1.11～14（B8～B5）没有引出到连接器。U1.1/DIR接3V3，U1.19/OE与J2.1、R1一端相连，R1另一端为3V3。实际R1阻值及U1完整型号仍应按实物确认。

用户已确认编码器已完整接好、PCB接口均已接满，Pmod A电源/地针已被既有接线使用。补充方案以保留这套接线为边界，不要求拆线回填。尚无本次逐根线束记录证明J2.2、J2.3、J1.5、J5.1、J5.2各落在哪个实体针；不据此臆造映射，也不判定已接错。完整接线确认不等于本次已经完成电气实测。

## 矛盾与解决

| 问题 | 证据与影响 | 处理 |
|---|---|---|
| 旧方案把四路编码器和Echo放在同一片LVC245 | 08号文档有Echo第五通道；实际PCB A5～A8接地，J1只引出四路 | Echo另外转换，不能接现板所谓空通道。若给接地的A5注入Echo，会把输出信号接到地 |
| 已占用电源针被再次列作直接插线位置 | 用户确认已有PCB占用；现板J2和J5也是输入，不是额外电源输出插口 | 在线束上加入绝缘分线端子，保持单一电源来源；不叠插杜邦母头 |
| 08号文档将右红外写成OUT2 | 厂家模块OUT1=INFRARED，OUT2=LIGHT | 两侧都读取OUT1；模块端1=GND、2=OUT2、3=OUT1、4=VCC，与底盘端针序分开 |
| 红外3.3V直读仍未实物验证 | 模块OUT上拉到自身VCC；改为5V却直连会使PL输入遇到5V | 推荐模块按确认的5V供电，两路OUT1也通过新增转换板；已有3.3V路径只有实测可靠后才保留 |
| 旧方案/OE接地与当前控制矛盾 | 08号文档旧示意OE=GND，12号文档和当前RTL要求JA9控制 | 保留现板JA9；以分线端子增加一支到新板/OE，新板10k上拉到3V3，不能用另一GPIO同时驱动该网 |
| 传感器既留原STM32信号又接PYNQ | 对接固件已移除本地传感器初始化；双连接可能受旧固件/断电回灌影响 | 原底盘仅提供已确认的5V与GND；传感器信号独立接新转换板/PYNQ |
| 将电机动力混入编码器PCB | 现板5ENC仅供霍尔板；六芯线含两根独立动力线 | 两根电机线去TB6612，四根编码器线去J3/J4；台架阶段动力插头断开 |

特别检查：若实际J5.1/5ENC接的是JA6或JA12，则与设计要求矛盾，因为它们是3.3V。J5.1应来自PYNQ Arduino POWER J7.4的5V。此处是检查条件，不表示已经发生该错误。

## 推荐补充方案：新三路传感器转换板

采用额外一片SN74LVC245A（下表按标准20脚封装，需核对完整料号和封装）。模块可以在小洞洞板上完成，不要求重做现有编码器PCB。

| 信号 | 新板5V侧 | 新板3.3V侧 | PYNQ最终落点 |
|---|---|---|---|
| 超声波Echo | A1 / pin2 | B1 / pin18 | JB8 / W16 |
| 左红外OUT1 | A2 / pin3 | B2 / pin17 | JA1 / Y18 |
| 右红外OUT1 | A3 / pin4 | B3 / pin16 | JA2 / Y19 |

- 新芯片pin20/VCC接PYNQ的3.3V分配端子，不能接传感器5V。
- pin10/GND接公共地；pin1/DIR接3.3V，固定A→B。
- pin19/OE接现有JA9使能线的新增分支，另加10k上拉至3.3V；该分支是一个输出驱动多个使能输入，不是合并传感器输出。
- pin5～9未用A输入接GND；pin11～15未用B输出留空。
- pin20与pin10附近放100nF去耦；板上引出明确的Echo/左IR/右IR输入输出及电源接口。
- 3.3V分配：现有PYNQ 3.3V供电线→绝缘分线端子→现编码器PCB J2.2、新转换板VCC。不要要求再占一个已经用掉的Pmod针。
- GND分配：PYNQ地、两块转换板、底盘信号地与三个传感器地连到公共地分配端子；动力大电流回路留在底盘。
- 5V来源分开：编码器保持PYNQ J7.4→现PCB J5.1；超声波和两块红外使用底盘实测确认的5V传感器电源。两路5V正极不连接。
- 红外仍有自己的模块上拉，不额外猜加输入上拉；Echo输出类型如未确认，先测波形，裸开漏输入则需核实后的5V侧上拉。

所需新增材料：SN74LVC245A一片、匹配封装转接板/小洞洞板、10k电阻、100nF电容、带绝缘保护的分线端子或分线线束、排针与连接线。未确认现有备件数量，不声称这些已经具备。

## 超声波Trig

JB7/V16继续输出Trig。3.3V直驱5V超声波的可靠性仍待验证。若不可靠，使用5V供电SN74AHCT125单向升电平：标准14脚封装pin14=5V、pin7=GND、pin1/1OE=GND、pin2/1A=JB7、pin3/1Y=模块Trig；电源近端100nF，未用输入固定、未用通道禁用、输出留空。不能用3.3V供电LVC245声称完成3.3V→5V升压。
