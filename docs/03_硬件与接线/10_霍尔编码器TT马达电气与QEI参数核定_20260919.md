## 2. 电机与编码器核定参数（手册P6参数表原文）

| 参数 | 1:48 | 1:90 |
|---|---|---|
| 额定电压 | 6V（建议工作电压范围3～9V） | 同左 |
| 额定电流 | 200mA | 200mA |
| 堵转电流 | 1.3A | 1.3A |
| 额定扭矩 | 1.5kg·cm | 2.4kg·cm |
| 输出轴转速 | 350rpm | 180rpm |
| 编码器类型 | AB相霍尔编码器，90°正交（可测速和方向） | 同左 |
| **编码器电压** | **4.5V～5V** | 同左 |
| 编码器线数 | 13线 | 13线 |
| 电机脉冲数 | 13×48×4=**2496** | 13×90×4=**4680** |
| 编码器说明 | **"编码器带上拉输出，单片机可直接采集"**（原文） | 同左 |

- 13线霍尔磁环位于**电机轴**（减速箱前），不是输出轮轴。手册P8原文："以1:48减速比为例，电机出轴线数为13x48=624线，四倍频后**电机输出轴**转一圈输出13x48x4=2496个计数"。
- x4（四倍频）是合法正交跳变计数，与PL `car_qei_core`的4状态FSM x4解码一致。
- **电气冲突记录**：P9典型控制框图顶部标注"编码器工作电压(5V、3.3V)"，与P6参数表"编码器电压4.5V～5V"矛盾。**以参数表为准：按4.5V～5V供电设计**；不得依据框图宣称3.3V供电已验证。若要试3.3V必须实测编码器输出幅度。
- "编码器带上拉输出"原文只能证明**编码器板已带上拉**，不能改写为"5V推挽"或"裸开漏"——厂家未给出输出级结构。对PYNQ侧的电气效果按**5V域高电平**处理：A/B严禁直连PL引脚。

## 3. PH2.0-6P针序（手册P7接口图）

手册图中6个引脚的标签自上而下依次为：

```text
电机线+ 、 编码器负极 、 编码器B相 、 编码器A相 、 编码器正极 、 电机线-
```

即中间四根编码器线从"电机线-"侧到"电机线+"侧依次为：**编码器正极、A相、B相、编码器负极**；两根电机线位于两端。

**警示**：手册图未标注线束颜色标准，不同批次颜色可能不同。接线前必须用万用表对实物逐针通断/电压确认（编码器正负极对地阻值、A/B相在慢转时的电平交替），不能仅凭颜色判断。接反编码器电源会永久损坏编码器板。

## 5. 用户已确认的实物配置（最高优先级）

1. **减速比1:48**（购买时已选）。
2. **轮胎未更换**：仍是最早无编码器小车的原装轮胎。
3. **65mm为手工粗测的名义直径**，不是精密标定值。
4. **只安装左前、右前两只编码器电机**；后轮仍是无编码器原装电机。
5. 首版定义：`QEI0=左前轮`、`QEI1=右前轮`，继续使用Pmod B 1—4脚（W14/Y14/T11/T10）。
6. 项目名义profile：`TT_48_ORIGINAL_WHEEL_FRONT_2`，临时SCALE=5362（左=右），带载标定后以实测值替换。

## 6. 左右侧统一驱动关系（不改STM32安全语义）

- TB6612只有左右两路，**同侧前后两个电机共用方向和PWM**：左侧控制量同时驱动左前（编码器）电机与左后（无编码器）电机，右侧同理。`safe_car.c`的`motors(left,right)`即左右侧模型。
- 左前QEI代表**左侧**实测速度，右前QEI代表**右侧**实测速度。后轮无独立反馈，**不能声称检测某个后轮单独打滑、堵转或速度**。
- `$P`帧的L/R与`motors(left,right)`继续表示左右侧PWM/方向请求；安全锁存、制动和限幅同时作用于同侧前后轮。当前阶段QEI用于侧速观测、里程候选和动态风险输入，不把RAW PWM协议改成速度闭环协议。
- 动态风险核以左右前轮速度较大值计算前进制动距离，对该接法保守且有效，保持不变；任一路QEI无效/过期仍失效安全停车。
- 原装后电机的真实减速比/空载转速**没有被本次编码器资料证明**，即使外形同为TT也不能假设与1:48前电机一致。到货后必须做：同侧前后轮悬空转速差测试、电流观察、反向一致性检查，再做落地直行测试。若机械顶牛或转速差过大，软件无法用共享PWM分别补偿，应改为匹配电机或独立驱动硬件，不得用错误PID掩盖。

## 7. 电平转换与上拉方案（首版两路）

```text
PYNQ Arduino POWER头J7 pin 4（板上VCC5V0）── 编码器VCC(4.5~5V)
   │  只给两块霍尔编码器板供电，不给电机供电；近端10uF+100nF
   └─ 编码器板(板载上拉, AB输出5V域)
   │
   ├─ A/B ──→ SN74LVC245A A侧(ch0/1=左前, ch2/3=右前)
   │            VCC=3.3V, DIR=高(固定A→B), B侧→Pmod B 1-4
   │            /OE: 10k上拉到3.3V默认禁用, JA9/W18在PL同步复位释放后拉低
   │            每片VCC-GND近端100nF去耦
   └─ GND ── 与PYNQ信号地单点共地
电机动力线 ── TB6612输出（禁止从Pmod给电机供电）
```

- 实购器件必须确认完整料号为**SN74LVC245A**（3.3V供电、输入可承受5V）。普通74HC245、TXS/TXB双向模块、BSS138 I²C板不等价，不得替代。
- 编码器板已带上拉，A/B线路**不另加外部上拉，XDC不启用PULLUP**。
- 编码器5V固定取自PYNQ Arduino POWER头**J7 pin 4的VCC5V0**（TUL R12原理图第4页/文本行260—278）；Pmod A/B电源脚是VCC3V3，**Pmod上没有5V脚**。此5V只给两块编码器霍尔板，电机动力仍由TB6612供电。上板先量得4.5—5.0V并确认电流/纹波，再接编码器。
- `/OE`定案：SN74LVC245A的`/OE`用10k上拉到3.3V，控制线接Pmod A **JA9/W18**。PL未配置时由外部上拉保持禁用；`car_board_video_wrapper`在同步复位期间输出高，复位释放后才输出低。禁止硬接GND，也不再使用人工跳线作为正常运行使能。
- 编码器5V先上电、PYNQ掉电/未配置、反向上电顺序均列入实测；未实测前`electrical_ready=false`。
- release前示波器确认：转换前A/B高低电平、转换后0—3.3V、慢转与额定转速边沿、无异常回灌或发热。
- HC-SR04 Echo与红外的处理方案不变，见08方案文档。

## 8. QEI SCALE与四组预设（契约v0.6）

契约公式（`pynq_fpga/nightly/interface_contract.md`）：`SCALE=round(轮周长mm/输出轮一圈x4计数×65536)`，Q16.16，生产复位0=未标定无效；PL计算`floor(scale×100000000/period_ticks)`。

```text
counts_per_wheel_rev = 13 × gear_ratio × 4
loaded_rollout_mm_per_rev = measured_distance_mm / measured_wheel_revolutions
SCALE = round(loaded_rollout_mm_per_rev / counts_per_wheel_rev × 65536)
# 用直径估算时 loaded_rollout_mm_per_rev = pi × diameter_mm
```

四组经独立脚本复算的资料预设（计算器`pynq_fpga/host/qei_calibration.py`，单测`tests/test_qei_calibration.py`）：

| 减速比 | 轮径 | x4计数/轮 | SCALE十进制 | SCALE十六进制 | 性质 |
|---|---|---:|---:|---:|---|
| 1:48 | 60mm | 2496 | 4949 | `0x00001355` | 资料对照 |
| 1:48 | 65mm | 2496 | **5362** | `0x000014F2` | **当前临时值**（TT_48_ORIGINAL_WHEEL_FRONT_2） |
| 1:90 | 60mm | 4680 | 2640 | `0x00000A50` | 资料对照（厂家STM32例程口径） |
| 1:90 | 65mm | 4680 | 2860 | `0x00000B2C` | 资料对照（厂家Arduino例程口径） |

5362的解码误差：0.081817627 mm/count对真值0.081812309 mm/count，相对误差0.0065%（1000mm行程约0.065mm）——但这是**直径估算误差之上的理论Q16.16量化误差**，轮径本身的粗测误差才是主导，仍需带载标定。

边沿率修正（废止旧"51Hz/0.5计数"口径）：

- 当前profile（1:48、65mm、2496计数/轮）：20cm/s → 边沿率约**2445Hz**，M法10ms窗口约**24.4计数**，计数充足。
- 旧"51Hz/0.5计数"是把电机轴13PPR误当轮轴计数（20cm/s÷(π×65mm)×13×4≈51Hz），**已废止**。
- 附录对照：1:90、65mm（4680计数/轮）→ 20cm/s约4584Hz，同样充足。

## 9. 到货后的标定与验收流程

1. **到货计数复核**：左前、右前轮分别做标记，电机动力线断开，手转输出轮整10圈。两路均应约**24960**个x4计数（`lab_acceptance.py sensor-check`/MMIO读POS_LIVE），以此复核1:48版本；若明显接近46800（1:90）或明显偏离24960，保持SCALE=0并停止联调。记录起止边界误差，多圈平均。
2. **带载滚动周长标定**：保持原装轮胎和正常整车载荷，左右轮分别测多圈实际滚动距离；`每圈滚动距离=总距离/圈数`。直接使用滚动周长，不用尺子夹外径替代带载标定。若两侧有效周长不同，两路分别标定。
3. **写SCALE**：`lab_acceptance.py qei-config`（需`--motor-disconnected`），显式给`--qei-profile TT_48_ORIGINAL_WHEEL_FRONT_2`（临时5362）或实测重算后的`--left-scale/--right-scale`；写后读回验证并保存证据`qei_config.json`。
4. **方向与单位验证**：正反转符号、mm/s量级、累计距离与动态风险输入联动。
5. **同侧前后轮一致性**：悬空同侧前后轮转速差、电流；落地直行偏差。不通过则换电机/改硬件，不调PID掩盖。
6. **电气实测**（release门禁）：第7节的示波器项与上电顺序项。
