# STM32 与 PYNQ 控制接口协议 V2

> 版本：V2.1（2026-09-17）。**两个固件版本并存**：
> - **演示版** `stm32预备程序/build_safe/safe_car.hex`（8792 字节）：超声波在 STM32 上，$P 帧不带 IR 字段，用于 PYNQ 到货前台架演示；
> - **对接版** `stm32_pynq对接版/build_safe/safe_car.hex`（7652 字节）：超声波+红外全部在 PYNQ 上，$P 帧带 IR 字段，**最终比赛固件**，详见 `stm32_pynq对接版/对接版说明.md`。
> PYNQ 侧统一用 `pc/pynq_link.py`（proto='pynq' 对接版 / 'demo' 演示版）。两版固件均已通过主机单元测试与模糊测试（30000 合法帧+30000 单字符破坏全拒绝）。

## 1. 物理链路（依据 V4.5 原理图与 K1 插座脚序）

```text
PYNQ-Z2 Pmod B 9 脚 V12 (TX) ──→ K1 脚4 RXD ──→ STM32 PA3 (USART2 RX)
PYNQ-Z2 Pmod B 10 脚 W13 (RX) ←── K1 脚3 TXD ←── STM32 PA2 (USART2 TX)
PYNQ-Z2 GND ──────────────────── K1 脚2 GND（只共地，不接 K1 脚1 VCC）
```

- 参数：**9600 / 8N1**（联调通过后双方同时升 115200，协议不变）。
- 接 PYNQ 前必须断电拔下蓝牙模块，蓝牙与 PYNQ 不得同时驱动 K1。
- USART1（PA9/PA10 → CH340 → Micro USB）仍为 115200 诊断口，输出 `$SAFE,...` 帧；底板 CH340 通路存在硬件故障（已确认与核心板无关），诊断优先用 DAP 虚拟串口或 USART2 旁路。
- 超声波迁移到 PYNQ 后，STM32 的 PA12/PA15 悬空；STM32 自身的距离保护改由 $P 帧上报的距离驱动（见 3.2）。

## 2. 帧总览

所有帧 ASCII 文本，`$` 起始、`#` 结束，无校验位。同一链路上共存两代帧：

| 方向 | 帧 | 周期 | 用途 |
|---|---|---|---|
| PYNQ→STM32 | `$P,<L>,<R>,<V>,<MMM>,<N>,<C>#` | **100 ms** | 左右轮驱动 + 距离上报 + 心跳 |
| PYNQ→STM32 | `$PSTOP#` | 事件 | PYNQ 判定高风险，请求立即锁存停车 |
| PYNQ→STM32 | `$PREL#` | 事件 | PYNQ 请求解锁（等价于发送停止帧，须满足解锁条件） |
| STM32→PYNQ | `$CAR,<L>,<R>,<LOCK>,<FAULT>,<MM>,<IR>,<DROP>#` | 300 ms | 状态回传 |
| 蓝牙 App→STM32 | `$d,d,d,d,d,d,d,d,d,d#`（原十字段帧） | 按键期间 | 蓝牙调试模式（此时超声波必须仍接 STM32） |
| PC→STM32(USB) | `$ARM#/$IDLE#/$HALT#/$BT#` | 事件 | USB 诊断控制，优先级高于 USART2 |

## 3. PYNQ→STM32 帧格式

### 3.1 驱动帧

**对接版（最终比赛固件）**：`$P,<L>,<R>,<V>,<MMM>,<IR>,<N>,<C>#`

**演示版**：`$P,<L>,<R>,<V>,<MMM>,<N>,<C>#`（无 IR 字段，其余相同）

| 字段 | 含义 | 范围 |
|---|---|---|
| `L` | 左轮 PWM，带符号 | -2400..2400，正=前进方向 |
| `R` | 右轮 PWM，带符号 | -2400..2400 |
| `V` | PYNQ 侧超声波有效性 | 0/1；V=0 时 STM32 立即按传感器无效锁车 |
| `MMM` | PYNQ PL 测得距离 | 0..9999 mm，V=0 时数值被忽略 |
| `IR` | 红外位图（仅对接版） | 0..3，bit0 左 bit1 右，1=检测到障碍；红外硬件在 PYNQ 上 |
| `N` | 序号 | 0..9 循环，供 PYNQ 侧自行核对丢帧（固件只查格式） |
| `C` | 校验和 | `'$'` 到 `N` 字段所有字符 ASCII 求和取低 8 位，两位**大写**十六进制 |

示例（已通过固件单元测试与模糊测试）：对接版 `$P,1200,1200,1,0888,0,0,6B#`、`$P,1200,-800,1,0200,0,1,58#`；演示版 `$P,1200,1200,1,0888,0,0F#`。

安全语义（STM32 侧逐条执行，PYNQ 无法绕过）：

1. `$P` 帧同时刷新**运动租约**：250 ms 内没有新 $P 帧 → 锁车（FAULT_LINK）。
2. `V=0` 或数据年龄超 200 ms → 锁车（FAULT_SENSOR）；实际上 200 ms 数据过期先于 250 ms 租约触发，形成双保险。
3. `MMM ≤ 200` → 只屏蔽**正向**轮速分量（正数清零），负向保留用于脱困；`≥ 250` 恢复（回差）。
4. 红外（对接版来自 $P 帧 IR 字段 / 演示版为本地 PA6/PA4）置位 → 立即锁存停车。
5. 校验和错误 → 帧被丢弃、`drop_count` 加一并锁车（FAULT_FRAME），错帧不刷新租约。
6. 锁存状态下 $P 帧只更新数据，不产生输出；解锁必须走 `$PREL#` 或停止帧路径（红外清除 + 距离 ≥250 + 数据新鲜 + 持续 300 ms）。

### 3.2 与蓝牙模式的关系

- 固件维护 `dist_source` 标志：收到首个 `$P` 帧后进入 PYNQ 模式（距离来自上报）；`$BT#` 或复位回到蓝牙模式（距离来自本地超声波）。
- **蓝牙模式只在超声波仍接 STM32 的当前接线下有效**。超声波物理迁移到 PYNQ 后，蓝牙模式没有近障保护，仅允许在台架低速验证时使用。

## 4. STM32→PYNQ 状态帧

```text
$CAR,<L>,<R>,<LOCK>,<FAULT>,<MM>,<IR>,<DROP>#\r\n
```

| 字段 | 含义 |
|---|---|
| `L`,`R` | 本轮**实际应用到电机的执行 PWM**（safe_outputs 结果：锁存/短刹为 0，近障屏蔽后正向分量已清零，含限幅）——不是 $P 帧的请求值；真实轮速由编码器测量，另有接口 |
| `LOCK` | 1=锁存停车中 |
| `FAULT` | 故障位图：1 上电锁 2 红外 4 近障 8 传感器无效/过期 16 链路超时 32 帧错误 64 模式帧 |
| `MM` | 最近有效距离（PYNQ 模式下即回显其上报值，用于核对链路） |
| `IR` | 红外位图：1 左 2 右 3 双侧 |
| `DROP` | $P 帧校验失败累计次数（非零说明 UART 链路受干扰，PYNQ 应告警） |

300 ms 周期、非阻塞发送。PYNQ 侧应检查：`LOCK=1` 时画面切入红色停车态；`DROP` 持续增长时在 AR 界面提示链路异常。

## 5. PYNQ 侧对接代码

参考实现见 `pc/pynq_link.py`（PYNQ 到货后复制到板上运行），核心即 pyserial：

```python
import serial, time

def build_p(left, right, valid, mm, seq, ir=0):
    body = f"$P,{left},{right},{int(valid)},{mm:04d},{ir},{seq}"   # 对接版格式
    return (body + f",{sum(body.encode()) & 0xFF:02X}#").encode()

ser = serial.Serial('/dev/ttyPS1', 9600, timeout=0.05)  # 实际设备名到货后核对
seq = 0
while True:
    seq = (seq + 1) % 10
    ser.write(build_p(1200, 1200, 1, 888, seq))
    time.sleep(0.10)  # 100 ms 周期，租约 250 ms
    line = ser.readline()
    if line.startswith(b'$CAR'):
        print(line.strip().decode())
```

联调顺序：先 9600 互发心跳 → 轮子悬空发 `$P,0,0,1,1000,0,0,2E#` + `$PREL#` 验证解锁 → `$P,600,600,1,0888,0,...` 低速 → 注入 V=0 / 断线验证停车 → 升 115200。（演示版固件联调时帧中不带 IR 字段。）

## 6. 已知边界

- 电池电压上报暂未实现：原理图存在 VB 分压网络，但原厂固件无 ADC 采集代码，且分压接入脚（PB10 附近网络）不具备 ADC 功能，需实物核对后再加；`$CAR` 帧字段已预留扩展位。
- PYNQ 模式下超声波 Trig/Echo 的物理接线迁到 Pmod B（W14/Y14/T11/T10/V16/W16 分配见《BST-4WD_V4.5与PYNQ-Z2硬件改装说明.md》）。
- 所有阈值（200/250/200ms/250ms）仍是未标定值，正式跑前必须做制动距离实测。
